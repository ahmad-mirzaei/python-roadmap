# بخش ۱ — متغیرها (Variables)

🌐 Language: **فارسی** | [English](README.md)

ما هر روز وسایل مختلف را داخل جعبه‌ ها، کشوها یا قفسه‌ ها نگهداری می‌ کنیم.

فرض کنید روی میزتان یک جعبه دارید.

روی آن نوشته‌اید:

**Books**

هر بار که کتاب جدیدی می‌ خرید، آن را داخل همین جعبه قرار می‌ دهید.

اگر بعداً کسی از شما بپرسد کتاب‌ هایت کجاست، کافی است بگویید:

> «داخل جعبه **Books**.»

وجود برچسب باعث می ‌شود بدون اینکه داخل جعبه را ببینید، بدانید چه چیزی در آن نگهداری می‌ شود.

در برنامه‌ نویسی نیز دقیقاً همین ایده وجود دارد.

با این تفاوت که به‌ جای کتاب، اطلاعات را نگهداری می‌ کنیم.

و به‌ جای برچسب روی جعبه، از **متغیر (Variable)** استفاده می‌ کنیم.

---

## متغیر چیست؟

**متغیر (Variable)** نامی است که برای نگهداری یک مقدار استفاده می‌شود.

می ‌توانید متغیر را مانند یک جعبه برچسب‌ دار تصور کنید.

- برچسب روی جعبه، نام متغیر است.
- چیزی که داخل جعبه قرار دارد، مقدار (Value) است.

برای مثال:

```python
name = "Ahmad"
```

در این مثال:

- `name` نام متغیر است.
- `"Ahmad"` مقداری است که داخل متغیر ذخیره شده است.
- علامت `=` مقدار را داخل متغیر قرار می‌ دهد.

---

مثال دیگری را ببینید:

```python
age = 25
```

حالا یک جعبه دیگر را تصور کنید.

روی آن نوشته شده است:

**age**

و داخل آن عدد **25** قرار دارد.

هر متغیر یک نام دارد و یک مقدار را نگهداری می‌ کند.

---

## چرا به متغیر نیاز داریم؟

فرض کنید متغیرها وجود نداشتند.

هر بار که می‌ خواستید نام، سن یا کشور یک شخص را در برنامه استفاده کنید، باید مقدار واقعی آن را دوباره و دوباره می‌ نوشتید.

متغیرها به ما اجازه می‌ دهند اطلاعات را یک‌بار ذخیره کنیم و هر زمان لازم بود دوباره از آن استفاده کنیم.

به همین دلیل برنامه‌ ها خواناتر، مرتب ‌تر و نگهداری آن‌ ها ساده‌ تر می‌ شود.

---

## خلاصه این بخش

- متغیر برای نگهداری اطلاعات استفاده می‌ شود.
- هر متغیر یک نام و یک مقدار دارد.
- متغیر را می‌ توان مانند یک جعبه برچسب‌ دار تصور کرد.
- علامت `=` مقدار را داخل متغیر قرار می‌ دهد.

# بخش ۲ — نام‌گذاری متغیرها

انتخاب نام مناسب برای متغیرها یکی از مهم‌ ترین مهارت‌ های برنامه‌ نویسی است.

هرچه نام متغیر واضح‌ تر باشد، خواندن و درک برنامه آسان‌ تر خواهد بود.

فرض کنید برنامه‌ ای را باز کرده‌ اید که متغیرهای آن به شکل زیر هستند:

```python
a = "Ahmad"
b = 25
c = "Canada"
```

آیا فقط با دیدن این کد می‌ توانید حدس بزنید هر متغیر چه اطلاعاتی را نگهداری می‌ کند؟

احتمالاً خیر.

حالا همین مثال را ببینید:

```python
name = "Ahmad"
age = 25
country = "Canada"
```

حتی بدون هیچ توضیحی، تقریباً مشخص است هر متغیر چه اطلاعاتی را نگهداری می‌ کند.

به همین دلیل انتخاب نام مناسب اهمیت زیادی دارد.

---

## قوانین نام‌گذاری متغیرها

پایتون چند قانون ساده برای نام‌ گذاری متغیرها دارد.

### قانون اول

نام متغیر باید با یک **حرف** یا **Underline (`_`)** شروع شود.

✔ صحیح

```python
name = "Ahmad"
_age = 25
```

✘ نادرست

```python
2name = "Ahmad"
```

---

### قانون دوم

نام متغیر می‌ تواند شامل حروف، اعداد و Underline باشد.

✔ صحیح

```python
student_name = "Ahmad"
score1 = 95
```

✘ نادرست

```python
student-name = "Ahmad"
```

علامت `-` در پایتون به معنی عملگر تفریق است و نمی‌ توان از آن در نام متغیر استفاده کرد.

---

### قانون سوم

پایتون بین حروف بزرگ و کوچک تفاوت قائل می‌شود.

سه متغیر زیر کاملاً متفاوت هستند:

```python
name = "Ahmad"
Name = "Bob"
NAME = "Charlie"
```

---

## بهترین روش

همیشه از نام‌ هایی استفاده کنید که مفهوم متغیر را بیان کنند.

نمونه‌ های مناسب:

```python
first_name
last_name
email
phone_number
price
```

تا حد امکان از نام‌ هایی مانند موارد زیر استفاده نکنید:

```python
a
x
temp1
abc
```

مگر در مثال‌ های آموزشی یا کدهای موقتی.

---

## خلاصه این بخش

- برای متغیرها نام‌ های واضح انتخاب کنید.
- قوانین نام‌ گذاری پایتون را رعایت کنید.
- نام متغیرها نسبت به حروف بزرگ و کوچک حساس هستند.
- نام مناسب باعث خواناتر شدن برنامه می‌ شود.

# بخش ۳ — نوع داده String

همه اطلاعات عدد نیستند.

گاهی لازم است متن‌ هایی مانند نام، کشور، شهر یا آدرس ایمیل را ذخیره کنیم.

در پایتون، متن با استفاده از نوع داده **String** ذخیره می‌ شود.

---

## String چیست؟

**String** دنباله‌ ای از کاراکترها است که داخل علامت نقل‌ قول قرار می‌ گیرد.

برای مثال:

```python
name = "Ahmad"
```

در این مثال، `"Ahmad"` یک String است.

پایتون به دلیل وجود علامت نقل‌ قول متوجه می‌ شود که این مقدار متن است.

---

## مثال‌های بیشتر

```python
country = "Iran"
```

```python
city = "Shiraz"
```

```python
email = "Ahmad@example.com"
```

همه این مقادیر از نوع String هستند، زیرا متن را نگهداری می‌ کنند.

---

## علامت نقل‌قول

در پایتون می‌ توانید از علامت نقل‌ قول دوتایی (`" "`) یا تکی (`' '`) استفاده کنید.

هر دو نمونه زیر صحیح هستند:

```python
language = "Python"
```

```python
language = 'Python'
```

بهتر است در کل پروژه از یک سبک ثابت استفاده کنید.

---

## چه زمانی از String استفاده می‌کنیم؟

هر زمان بخواهید متن ذخیره کنید، باید از String استفاده کنید.

برای مثال:

- نام افراد
- شهرها
- کشورها
- آدرس ایمیل
- پیام‌ها

---

> 💡 **نکته کاربردی**
>
> اگر مقداری داخل علامت نقل‌ قول قرار بگیرد، حتی اگر فقط شامل عدد باشد، باز هم از نوع String است.
>
> مثال:
>
> ```python
> code = "12345"
> ```
>
> این مقدار متن است، نه عدد.

---

## اشتباه رایج مبتدیان

بسیاری از افراد تازه‌ کار متن را بدون علامت نقل‌ قول می‌ نویسند.

نادرست:

```python
name = Ahmad
```

درست:

```python
name = "Ahmad"
```

اگر علامت نقل ‌قول را ننویسید، پایتون تصور می‌ کند `Ahmad` نام یک متغیر دیگر است.

---

## خلاصه این بخش

- String برای نگهداری متن استفاده می‌شود.
- متن باید داخل علامت نقل‌ قول قرار بگیرد.
- می‌ توان از نقل‌ قول تکی یا دوتایی استفاده کرد.
- متن بدون نقل‌ قول به‌عنوان String شناخته نمی‌ شود.
