# بخش ۱ — عملگر و عملوند چیست؟

🌐 Language: **فارسی** | [English](../README.md)

در برنامه نویسی معمولاً لازم است کارهایی مانند موارد زیر را انجام دهیم:

* جمع کردن عددها
* کم کردن مقدارها
* مقایسه دو اطلاعات
* ترکیب داده ها

برای انجام این کارها، پایتون از **عملگرها (Operators)** استفاده می کند.

---

## یک مثال روزمره

یک ماشین حساب را تصور کنید.

اگر بنویسید:

```text
5 + 3
```

ماشین حساب یک عملیات انجام می دهد.

* `5` یک مقدار است.
* `3` یک مقدار دیگر است.
* `+` به ماشین حساب می گوید این دو مقدار را با هم جمع کند.

در برنامه نویسی هم دقیقاً همین اتفاق می افتد.

---

## عملگر چیست؟

**عملگر (Operator)** نمادی است که به پایتون می گوید چه عملی انجام دهد.

نمونه ها:

```python
+
-
*
/
=
```

هر عملگر معنی مشخصی دارد.

---

## عملوند چیست؟

**عملوند (Operand)** مقداری است که عملگر روی آن کار می کند.

مثال:

```python
5 + 3
```

در این عبارت:

* `5` → عملوند
* `3` → عملوند
* `+` → عملگر

---

## مثال دیگر

```python
price = 100
discount = 20

final_price = price - discount
```

در عبارت:

```python
price - discount
```

* `price` یک عملوند است.
* `discount` یک عملوند است.
* `-` عملگر است.

پایتون عملوند دوم را از عملوند اول کم می کند.

---

## چرا عملگرها مهم هستند؟

بدون عملگرها، برنامه فقط می توانست اطلاعات را ذخیره کند و هیچ کاری روی آن ها انجام ندهد.

عملگرها به برنامه اجازه می دهند:

* مجموع را محاسبه کند.
* اختلاف را پیدا کند.
* مقدارها را مقایسه کند.
* تصمیم گیری کند.
* اطلاعات را به روز کند.

تقریباً تمام برنامه های پایتون از عملگرها استفاده می کنند.

---

## خلاصه این بخش

* **عملگر** نمادی است که یک عمل انجام می دهد.
* **عملوند** مقداری است که عملگر روی آن کار می کند.
* مثال:

```python
5 + 3
```

در این عبارت، `+` عملگر است و `5` و `3` عملوند هستند.

در بخش بعد با مهم ترین عملگرهای حسابی پایتون آشنا می شوید.

---

# بخش ۲ — عملگر های حسابی

در بخش قبل یاد گرفتید عملگر و عملوند چیست.

حالا نوبت آن است که با پرکاربرد ترین عملگر های پایتون آشنا شوید.

به این عملگر ها **عملگر های حسابی (Arithmetic Operators)** گفته می شود، زیرا برای انجام محاسبات ریاضی استفاده می شوند.

---

## یک مثال روزمره

یک ماشین حساب را تصور کنید.

وقتی وارد می کنید:

```
15 + 5
```

ماشین حساب عمل جمع را انجام می دهد.

اگر وارد کنید:

```
20 - 8
```

عمل تفریق انجام می شود.

پایتون نیز دقیقاً به همین شکل کار می کند.

برای انجام محاسبات ریاضی از عملگر های حسابی استفاده می کند.

---

## عملگر جمع (+)

عملگر جمع دو مقدار را با یکدیگر جمع می کند.

مثال:

```python
a = 10
b = 5

result = a + b

print(result)
```

خروجی:

```text
15
```

---

## عملگر تفریق (-)

عملگر تفریق یک مقدار را از مقدار دیگر کم می کند.

مثال:

```python
a = 20
b = 8

result = a - b

print(result)
```

خروجی:

```text
12
```

---

## عملگر ضرب (*)

عملگر ضرب دو مقدار را در یکدیگر ضرب می کند.

مثال:

```python
a = 6
b = 4

result = a * b

print(result)
```

خروجی:

```text
24
```

---

## عملگر تقسیم (/)

عملگر تقسیم یک مقدار را بر مقدار دیگر تقسیم می کند.

مثال:

```python
a = 20
b = 5

result = a / b

print(result)
```

خروجی:

```text
4.0
```

توجه کنید که نتیجه همیشه به صورت عدد اعشاری برگردانده می شود.

---

## عملگر تقسیم صحیح (//)

عملگر تقسیم صحیح دو عدد را بر هم تقسیم می کند و فقط بخش صحیح نتیجه را برمی گرداند.

مثال:

```python
a = 20
b = 6

result = a // b

print(result)
```

خروجی:

```text
3
```

قسمت اعشاری نتیجه حذف می شود.

---

## عملگر باقیمانده تقسیم (%)

عملگر `%` باقیمانده تقسیم دو عدد را برمی گرداند.

مثال:

```python
a = 20
b = 6

result = a % b

print(result)
```

خروجی:

```text
2
```

زیرا:

```
20 = (6 × 3) + 2
```

باقیمانده برابر با `2` است.

---

## عملگر توان (**)

عملگر `**` یک عدد را به توان عدد دیگر می رساند.

مثال:

```python
result = 2 ** 3

print(result)
```

خروجی:

```text
8
```

زیرا:

```
2 × 2 × 2 = 8
```

---

## خلاصه عملگر ها

| عملگر | کاربرد | مثال |
|-------|---------|------|
| `+` | جمع | `10 + 5` |
| `-` | تفریق | `20 - 8` |
| `*` | ضرب | `6 * 4` |
| `/` | تقسیم | `20 / 5` |
| `//` | تقسیم صحیح | `20 // 6` |
| `%` | باقیمانده تقسیم | `20 % 6` |
| `**` | توان | `2 ** 3` |

---

## اشتباه رایج مبتدیان

بسیاری از افراد مبتدی عملگر `/` و `//` را با هم اشتباه می گیرند.

مثال:

```python
20 / 6
```

خروجی:

```text
3.3333333333333335
```

اما:

```python
20 // 6
```

خروجی:

```text
3
```

عملگر `/` نتیجه واقعی تقسیم را برمی گرداند.

عملگر `//` فقط بخش صحیح نتیجه را برمی گرداند.

---

## خلاصه این بخش

- عملگر های حسابی برای انجام محاسبات ریاضی استفاده می شوند.
- پایتون هفت عملگر حسابی اصلی دارد.
- `/` و `//` دو عملگر متفاوت هستند.
- `%` باقیمانده تقسیم را برمی گرداند.
- `**` برای محاسبه توان استفاده می شود.

---

# بخش ۳ — عملگر های انتساب

در درس های قبلی بارها از عملگر انتساب استفاده کرده اید.

برای مثال:

```python
age = 36
```

اما واقعاً این خط چه کاری انجام می دهد؟

عملگر انتساب یک مقدار را داخل یک متغیر قرار می دهد.

پایتون علاوه بر عملگر `=` چند عملگر میانبر هم دارد که باعث می شوند کد کوتاه تر و خواناتر شود.

---

## عملگر انتساب (=)

عملگر `=` یک مقدار را به یک متغیر اختصاص می دهد.

مثال:

```python
score = 100
```

حالا متغیر `score` مقدار `100` را نگهداری می کند.

---

## جمع و انتساب (+=)

به جای نوشتن:

```python
score = score + 10
```

می توانید بنویسید:

```python
score += 10
```

هر دو دقیقاً یک نتیجه دارند.

---

## تفریق و انتساب (-=)

مثال:

```python
score -= 5
```

یعنی:

```python
score = score - 5
```

---

## ضرب و انتساب (*=)

مثال:

```python
score *= 2
```

یعنی:

```python
score = score * 2
```

---

## تقسیم و انتساب (/=)

مثال:

```python
score /= 4
```

یعنی:

```python
score = score / 4
```

---

## جدول خلاصه

| عملگر | معادل |
|-------|--------|
| `=` | اختصاص مقدار |
| `+=` | `x = x + value` |
| `-=` | `x = x - value` |
| `*=` | `x = x * value` |
| `/=` | `x = x / value` |
