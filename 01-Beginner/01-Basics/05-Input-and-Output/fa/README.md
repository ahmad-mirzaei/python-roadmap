# بخش ۱ — دریافت اطلاعات از کاربر

تا اینجا برنامه هایی ساختید که اطلاعات مورد نیاز خود را از داخل کد دریافت می کردند.

برای مثال:

```python
name = "Ahmad"
age = 36
```

مقدار ها از قبل مشخص هستند.

اگر شخص دیگری بخواهد از برنامه استفاده کند، باید مقدار های داخل کد به صورت دستی تغییر کنند.

اما برنامه های واقعی معمولاً نیاز دارند اطلاعات را از کاربر دریافت کنند.

---

## یک مثال روزمره

یک فرم ثبت نام در یک وب سایت را تصور کنید.

وب سایت از قبل نمی داند:

- نام شما چیست.
- ایمیل شما چیست.
- سن شما چقدر است.

به همین دلیل از شما می خواهد این اطلاعات را وارد کنید.

سپس از این اطلاعات برای ساخت حساب کاربری استفاده می کند.

برنامه های پایتون هم به همین شکل کار می کنند.

آن ها می توانند در زمان اجرای برنامه، اطلاعات را از کاربر دریافت کنند و از آن استفاده کنند.

---

## اطلاعات ثابت و اطلاعات پویا

این دو حالت را مقایسه کنید.

### اطلاعات ثابت:

```python
name = "Ahmad"
```

مقدار از قبل داخل برنامه نوشته شده است.

### اطلاعات پویا:

```python
name = get_information_from_user()
```

برنامه مقدار را از کاربر دریافت می کند.

برنامه های پویا انعطاف بیشتری دارند، چون می توانند برای کاربران مختلف کار کنند.

---

## چرا به ورودی کاربر نیاز داریم؟

دریافت اطلاعات از کاربر به برنامه اجازه می دهد:

- سوال بپرسد.
- پاسخ شخصی سازی شده ایجاد کند.
- با کاربران مختلف کار کند.
- به انتخاب های کاربر واکنش نشان دهد.

مثال:

- سیستم ورود از کاربر نام کاربری می خواهد.
- ماشین حساب عدد دریافت می کند.
- بازی ها انتخاب بازیکن را دریافت می کنند.

---

## خلاصه این بخش

- برنامه ها می توانند از اطلاعات ثابت یا اطلاعات کاربر استفاده کنند.
- برنامه های واقعی معمولاً اطلاعات را از کاربر دریافت می کنند.
- ورودی کاربر باعث انعطاف بیشتر برنامه ها می شود.

# بخش ۲ — تابع input()

در بخش قبل یاد گرفتید چرا برنامه ها به اطلاعات کاربر نیاز دارند.

حالا یاد می گیریم پایتون چگونه این اطلاعات را دریافت می کند.

پایتون برای دریافت اطلاعات از کاربر از تابع `input()` استفاده می کند.

---

## input() چیست؟

تابع `input()` اجرای برنامه را متوقف می کند و منتظر می ماند تا کاربر چیزی وارد کند.

برای مثال:

```python
name = input("Enter your name: ")
```

وقتی پایتون این کد را اجرا می کند، پیام زیر نمایش داده می شود:

```text
Enter your name:
```

سپس برنامه منتظر می ماند تا کاربر یک مقدار وارد کند.

---

## یک مثال روزمره

یک دستگاه خودپرداز (ATM) را تصور کنید.

دستگاه خودپرداز از قبل رمز شما را نمی داند.

به همین دلیل از شما می پرسد:

> «لطفاً رمز خود را وارد کنید.»

سپس منتظر پاسخ شما می ماند و از آن اطلاعات استفاده می کند.

تابع `input()` نیز تقریباً همین کار را انجام می دهد.

این تابع یک سوال از کاربر می پرسد و پاسخ او را دریافت می کند.

---

## بررسی کد

این مثال را ببینید:

```python
name = input("Enter your name: ")
```

این کد دو بخش دارد:

### پیام نمایش داده شده

```python
"Enter your name: "
```

این همان سوالی است که به کاربر نمایش داده می شود.

### مقدار وارد شده توسط کاربر

پاسخی که کاربر وارد می کند داخل متغیر زیر ذخیره می شود:

```python
name
```

این متغیر اطلاعات را نگهداری می کند تا برنامه بتواند بعداً از آن استفاده کند.

---

## مثال دیگر

```python
country = input("Where do you live? ")
```

برنامه یک سوال از کاربر می پرسد.

پاسخ کاربر داخل متغیر زیر ذخیره می شود:

```python
country
```

---

## نکته مهم

فعلاً فقط این نکته را به خاطر بسپارید:

تابع `input()` اطلاعات را از کاربر دریافت می کند.

در بخش های بعد یاد می گیرید چگونه با انواع مختلف ورودی، مانند عددها، کار کنید.

---

## خلاصه این بخش

- `input()` اطلاعات را از کاربر دریافت می کند.
- برنامه تا زمان وارد کردن مقدار توسط کاربر منتظر می ماند.
- نتیجه ورودی را می توان داخل یک متغیر ذخیره کرد.
- ورودی کاربر باعث تعاملی شدن برنامه می شود.

# بخش ۳ — ذخیره ورودی کاربر در متغیرها

در بخش قبل یاد گرفتید که تابع `input()` اطلاعات را از کاربر دریافت می کند.

اما دریافت اطلاعات فقط مرحله اول است.

یک برنامه باید بتواند این اطلاعات را به خاطر بسپارد.

پایتون ورودی کاربر را داخل متغیرها ذخیره می کند.

---

## یک مثال روزمره

فرض کنید در یک فرم ثبت نام اطلاعات خود را وارد می کنید.

نام خود را وارد می کنید:

```
Ahmad
```

وب سایت فقط نام شما را دریافت نمی کند و بعد آن را فراموش نمی کند.

اطلاعات شما را ذخیره می کند تا بعداً بتواند از آن استفاده کند.

برنامه های پایتون هم به همین شکل کار می کنند.

آن ها پاسخ های کاربر را داخل متغیرها نگهداری می کنند.

---

## ذخیره ورودی

این مثال را ببینید:

```python
name = input("Enter your name: ")
```

وقتی کاربر مقدار زیر را وارد کند:

```text
Ahmad
```

پایتون آن مقدار را داخل متغیر زیر ذخیره می کند:

```python
name
```

حالا برنامه نام کاربر را به خاطر دارد.

---

## استفاده از اطلاعات ذخیره شده

بعد از ذخیره اطلاعات، برنامه می تواند در بخش های بعدی از آن استفاده کند.

مثال:

```python
name = input("Enter your name: ")

print(name)
```

اگر کاربر وارد کند:

```text
Ahmad
```

خروجی:

```text
Ahmad
```

برنامه مقدار ذخیره شده داخل متغیر را نمایش می دهد.

---

## چند ورودی مختلف

یک برنامه می تواند اطلاعات مختلف را داخل متغیرهای جداگانه ذخیره کند.

مثال:

```python
name = input("Enter your name: ")
country = input("Enter your country: ")
```

حالا برنامه دو اطلاعات جداگانه دارد:

- نام کاربر
- کشور کاربر

هر مقدار متغیر مخصوص خودش را دارد.

---

## چرا ورودی کاربر را ذخیره می کنیم؟

ذخیره اطلاعات به برنامه اجازه می دهد:

- بعداً از اطلاعات استفاده کند.
- پیام های شخصی سازی شده ایجاد کند.
- بر اساس اطلاعات کاربر تصمیم بگیرد.

بدون ذخیره کردن ورودی، برنامه اطلاعات را دریافت می کند و بلافاصله آن را از دست می دهد.

---

## خلاصه این بخش

- ورودی کاربر را می توان داخل متغیرها ذخیره کرد.
- هر متغیر می تواند یک اطلاعات جداگانه را نگهداری کند.
- اطلاعات ذخیره شده را می توان در ادامه برنامه استفاده کرد.
