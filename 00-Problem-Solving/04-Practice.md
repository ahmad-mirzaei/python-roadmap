## 📖 Overview

Congratulations!

You've completed the theoretical part of the **Problem Solving** module.

> Programming isn't about writing code first.

---

## 🎯 Learning Objectives

After completing this lesson, you will be able to:

- Analyze programming problems.
- Identify the input and output.
- Break problems into smaller steps.
- Write simple algorithms.
- Prepare yourself for writing Python code.

---

## 🧠 Problem Solving Checklist

For every exercise in this lesson, answer these questions before thinking about the solution:

1. What is the problem?
2. What is the input?
3. What is the expected output?
4. What steps are needed to solve it?
5. Can the problem be divided into smaller tasks?

If you can answer these five questions, you're ready to write code.

## 📝 Practice 1 — Calculate Age

### Problem

A person tells you their birth year.

Describe the steps needed to calculate their age.

---

### 🤔 Think First

Ask yourself:

- What information do I have?
- What should I calculate?
- What is the relationship between the input and the output?

---

### ✅ Sample Algorithm

1. Read the birth year.
2. Read the current year.
3. Subtract the birth year from the current year.
4. Display the age.

---

## 📝 Practice 2 — Temperature Converter

### Problem

Convert a temperature from Celsius to Fahrenheit.

---

### 🤔 Think First

- What is the input?
- What is the output?
- What formula should be used?

---

### ✅ Sample Algorithm

1. Read the temperature in Celsius.
2. Multiply it by 9.
3. Divide the result by 5.
4. Add 32.
5. Display the Fahrenheit temperature.

---

## 💡 Remember

At this stage, **you are practicing thinking—not programming.**

Don't worry about Python syntax.

Focus on understanding the problem and writing the algorithm.

---

## 📝 Practice 3 — Even or Odd

### Problem

Determine whether a number is even or odd.

---

### 🤔 Think First

Ask yourself:

- What information do I have?
- What should the program display?
- How can I determine if a number is even?

---

### ✅ Sample Algorithm

1. Read a number.
2. Divide the number by 2.
3. Check the remainder.
4. If the remainder is 0, display "Even".
5. Otherwise, display "Odd".

---

## 📝 Practice 4 — ATM Withdrawal

### Problem

A customer wants to withdraw money from an ATM.

Write the steps required to complete the withdrawal.

---

### 🤔 Think First

What should happen before giving the money?

---

### ✅ Sample Algorithm

1. Insert the bank card.
2. Enter the PIN.
3. Verify the PIN.
4. Enter the withdrawal amount.
5. Check if the account has enough balance.
6. Deduct the amount from the balance.
7. Dispense the cash.
8. Print the receipt (optional).

---

## 📝 Practice 5 — Student Grade

### Problem

Determine whether a student has passed or failed.

The passing score is 50.

---

### 🤔 Think First

- What is the input?
- What should the output be?
- What condition should be checked?

---

### ✅ Sample Algorithm

1. Read the student's score.
2. Compare it with 50.
3. If the score is greater than or equal to 50, display "Pass".
4. Otherwise, display "Fail".

---

## 📝 Practice 6 — Online Shopping

### Problem

Calculate the total cost of three products.

---

### 🤔 Think First

How would an online store calculate your total before checkout?

---

### ✅ Sample Algorithm

1. Read the price of the first product.
2. Read the price of the second product.
3. Read the price of the third product.
4. Add the prices together.
5. Display the total cost.

---

> [!TIP]
> Every programming problem becomes easier when you first understand the process, then write the algorithm, and only after that write the code.
