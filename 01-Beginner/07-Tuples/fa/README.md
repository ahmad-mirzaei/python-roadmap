## ۱. Tuple چیست؟

**تاپل** یکی از انواع داده در پایتون است که می تواند چند مقدار را در کنار یکد یگر نگه دارد.

تاپل شبیه لیست است، اما یک تفاوت مهم دارد:

```text
List  → قابل تغییر است
Tuple → بعد از ساخت قابل تغییر نیست
```

برای مثال:

```python
fruits = ("Apple", "Banana", "Orange")

print(fruits)
```

خروجی:

```text
('Apple', 'Banana', 'Orange')
```

مقادیر مختلف درون یک تاپل قرار گرفته اند.

## ۲. ساخت Tuple

برای ساخت تاپل معمولاً عناصر را داخل پرانتز `()` قرار می دهیم.

```python
numbers = (10, 20, 30, 40)

print(numbers)
```

خروجی:

```text
(10, 20, 30, 40)
```

یک تاپل می تواند شامل انواع مختلف داده نیز باشد:

```python
student = ("Ali", 20, 18.5)

print(student)
```

خروجی:

```text
('Ali', 20, 18.5)
```

## ۳. تفاوت Tuple و List

برای ساخت لیست از براکت استفاده می کنیم:

```python
fruits = ["Apple", "Banana", "Orange"]
```

برای ساخت تاپل معمولاً از پرانتز استفاده می کنیم:

```python
fruits = ("Apple", "Banana", "Orange")
```

تفاوت مهم این دو در تغییر پذیری آن هاست.

List قابل تغییر است:

```python
fruits = ["Apple", "Banana", "Orange"]

fruits[0] = "Mango"

print(fruits)
```

خروجی:

```text
['Mango', 'Banana', 'Orange']
```

اما Tuple را نمی توان به این شکل تغییر داد:

```python
fruits = ("Apple", "Banana", "Orange")

fruits[0] = "Mango"
```

پایتون خطا ایجاد می کند، چون عناصر تاپل بعد از ساخته شدن قابل تغییر نیستند.

## ۴. چه زمانی از Tuple استفاده می کنیم؟

تاپل زمانی کاربردی است که چند مقدار داشته باشیم و بخواهیم این مقادیر ثابت باقی بمانند.

برای مثال:

```python
location = (51.5074, -0.1278)

print(location)
```

خروجی:

```text
(51.5074, -0.1278)
```

این تاپل می تواند یک جفت مقدار ثابت را نمایش دهد.

مثال دیگر:

```python
birthday = (15, 8, 2005)

print(birthday)
```

خروجی:

```text
(15, 8, 2005)
```

## ۵. یک نکته مهم برای شروع

تاپل فقط به معنی «لیست با پرانتز» نیست.

مفهوم اصلی تاپل این است که **تغییر ناپذیر** است.

یعنی بعد از ساخته شدن تاپل نمی توانیم مستقیماً عناصر آن را تغییر دهیم، اضافه کنیم یا حذف کنیم.

در بخش های بعدی این مفهوم را دقیق تر بررسی می کنیم.

فعلاً به خاطر داشته باشید:

```text
List  → قابل تغییر
Tuple → تغییرناپذیر
```

# بخش ۲ — ساخت Tuple

## ۱. ساخت یک Tuple

معمولاً برای ساخت تاپل چند مقدار را داخل پرانتز `()` قرار می دهیم و عناصر را با کاما از هم جدا می کنیم.

```python
fruits = ("Apple", "Banana", "Orange")

print(fruits)
```

خروجی:

```text
('Apple', 'Banana', 'Orange')
```

کاماها مهم هستند، چون عناصر تاپل را از یکدیگر جدا می کنند.

## ۲. ساخت Tuple از اعداد

یک Tuple می تواند شامل اعداد باشد:

```python
numbers = (10, 20, 30, 40)

print(numbers)
```

خروجی:

```text
(10, 20, 30, 40)
```

## ۳. ساخت Tuple با انواع مختلف داده

یک تاپل می تواند شامل انواع مختلف داده باشد.

```python
student = ("Ali", 20, 18.5, True)

print(student)
```

خروجی:

```text
('Ali', 20, 18.5, True)
```

## ۴. ساخت Tuple خالی

می توانیم با استفاده از پرانتزهای خالی یک تاپل خالی بسازیم:

```python
empty_tuple = ()

print(empty_tuple)
```

خروجی:

```text
()
```

یک Tuple خالی هیچ عنصری ندارد.

## ۵. ساخت Tuple تک عنصری

یک نکته بسیار مهم این است که برای ساخت تاپل دارای یک عنصر، به یک کاما نیاز داریم.

این یک Tuple نیست:

```python
number = (10)

print(type(number))
```

خروجی:

```text
<class 'int'>
```

پایتون `(10)` را یک عبارت معمولی از نوع عدد صحیح در نظر می گیرد.

برای ساخت یک تاپل تک عنصری باید کاما قرار دهیم:

```python
number = (10,)

print(type(number))
```

خروجی:

```text
<class 'tuple'>
```

این کاما مهم است.

## ۶. ساخت Tuple بدون پرانتز

پایتون اجازه می دهد بدون نوشتن مستقیم پرانتز نیز تاپل بسازیم.

```python
fruits = "Apple", "Banana", "Orange"

print(fruits)
```

خروجی:

```text
('Apple', 'Banana', 'Orange')
```

پایتون مقادیر جدا شده با کاما را به عنوان یک تاپل تشخیص می دهد.

با این حال، استفاده از پرانتز برای افراد تازه کار معمولاً واضح تر است:

```python
fruits = ("Apple", "Banana", "Orange")
```

## ۷. ساخت Tuple از یک List

می توانیم با استفاده از `tuple()` یک List را به تاپل تبدیل کنیم.

```python
fruits = ["Apple", "Banana", "Orange"]

fruits_tuple = tuple(fruits)

print(fruits_tuple)
```

خروجی:

```text
('Apple', 'Banana', 'Orange')
```

در بخش های بعدی تبدیل بین لیست و تاپل را با جزئیات بیشتری بررسی می کنیم.

## ۸. بررسی نوع داده

با استفاده از `type()` می توانیم بررسی کنیم که یک مقدار از نوع تاپل است یا نه.

```python
colors = ("Red", "Green", "Blue")

print(type(colors))
```

خروجی:

```text
<class 'tuple'>
```

## ۹. قانون مهم

هنگام ساخت Tuple این موارد را به خاطر داشته باشید:

```text
چند عنصر      → عناصر با کاما از هم جدا می شوند
یک عنصر       → قرار دادن کاما ضروری است
Tuple خالی    → ()
```

برای مثال:

```python
a = ()
b = (10,)
c = (10, 20, 30)
```

# بخش ۳ — دسترسی به عناصر Tuple

## ۱. دسترسی به عناصر با Indexing

درست مانند لیست، می توانیم با استفاده از اندیس به عناصر تاپل دسترسی داشته باشیم.

پایتون اندیس ها را از `0` شروع می کند.

```python
fruits = ("Apple", "Banana", "Orange")

print(fruits[0])
print(fruits[1])
print(fruits[2])
```

خروجی:

```text
Apple
Banana
Orange
```

## ۲. استفاده از اندیس های منفی

می توانیم از اندیس های منفی نیز استفاده کنیم.

`-1` به آخرین عنصر، `-2` به دومین عنصر از انتها و به همین ترتیب اشاره می کند.

```python
fruits = ("Apple", "Banana", "Orange")

print(fruits[-1])
print(fruits[-2])
print(fruits[-3])
```

خروجی:

```text
Orange
Banana
Apple
```

## ۳. دسترسی به یک عنصر مشخص

می توانیم با استفاده از اندیس به هر عنصری که نیاز داریم دسترسی داشته باشیم.

```python
numbers = (10, 20, 30, 40, 50)

print(numbers[3])
```

خروجی:

```text
40
```

اندیس `3` به چهارمین عنصر اشاره می کند، چون شمارش اندیس ها از `0` شروع می شود.

## ۴. استفاده از Indexing با انواع مختلف داده

Indexing مستقل از نوع داده های ذخیره شده در Tuple است.

```python
student = ("Ali", 20, 18.5, True)

print(student[0])
print(student[1])
print(student[2])
print(student[3])
```

خروجی:

```text
Ali
20
18.5
True
```

## ۵. Indexing در Tuple تو در تو

یک Tuple می تواند شامل یک Tuple دیگر باشد.

می توانیم با استفاده از چند اندیس به یک عنصر داخل تاپل تو در تو دسترسی داشته باشیم.

```python
student = ("Ali", (18, 20, 17))

print(student[1])
print(student[1][0])
```

خروجی:

```text
(18, 20, 17)
18
```

در اینجا:

```text
student[1]
```

به تاپل داخلی دسترسی پیدا می کند.

سپس:

```text
student[1][0]
```

به اولین عنصر تاپل داخلی دسترسی پیدا می کند.

تاپل تو در تو را در بخش های بعدی با جزئیات بیشتری بررسی می کنیم.

## ۶. خارج شدن از محدوده اندیس

اندیسی که استفاده می کنیم باید در تاپل وجود داشته باشد.

برای مثال:

```python
fruits = ("Apple", "Banana", "Orange")

print(fruits[3])
```

این کد باعث ایجاد خطا می شود، زیرا اندیس های موجود عبارت اند از:

```text
0
1
2
```

اندیس `3` وجود ندارد.

## ۷. نکته مهم

Indexing در تاپل از نظر پایه دقیقاً مانند Indexing در لیست کار می کند.

برای مثال:

```python

```

خروجی:

```text

```

تفاوت اصلی در روش دسترسی به عناصر نیست.

تفاوت مهم این است که عناصر تاپل بعد از ساخته شدن قابل تغییر نیستند.

# بخش ۴ — برش Tuple

## ۱. Tuple Slicing چیست؟

درست مانند List، می توانیم با استفاده از Slicing بخشی از یک Tuple را انتخاب کنیم.

ساختار اصلی به این شکل است:

```python
tuple[start:stop]
```

اندیس `start` در نتیجه قرار می گیرد، اما اندیس `stop` در نتیجه قرار نمی گیرد.

برای مثال:

```python
fruits = ("Apple", "Banana", "Orange", "Mango", "Grape")

print(fruits[1:4])
```

خروجی:

```text
('Banana', 'Orange', 'Mango')
```

اندیس های `1`، `2` و `3` در نتیجه قرار می گیرند، اما اندیس `4` قرار نمی گیرد.

## ۲. برش از ابتدای Tuple

می توانیم اندیس `start` را خالی بگذاریم.

```python
numbers = (10, 20, 30, 40, 50)

print(numbers[:3])
```

خروجی:

```text
(10, 20, 30)
```

یعنی:

```text
از ابتدای Tuple شروع کن
قبل از اندیس 3 متوقف شو
```

## ۳. برش تا انتهای Tuple

می توانیم اندیس `stop` را نیز خالی بگذاریم.

```python
numbers = (10, 20, 30, 40, 50)

print(numbers[2:])
```

خروجی:

```text
(30, 40, 50)
```

یعنی:

```text
از اندیس 2 شروع کن
تا انتهای Tuple ادامه بده
```

## ۴. کپی کردن Tuple با Slicing

می توانیم با استفاده از Slicing تمام عناصر Tuple را انتخاب کنیم.

```python
fruits = ("Apple", "Banana", "Orange")

new_fruits = fruits[:]

print(new_fruits)
```

خروجی:

```text
('Apple', 'Banana', 'Orange')
```

## ۵. استفاده از Step

می توانیم مقدار سومی را نیز در Slicing قرار دهیم:

```python
tuple[start:stop:step]
```

برای مثال:

```python
numbers = (10, 20, 30, 40, 50, 60)

print(numbers[0:6:2])
```

خروجی:

```text
(10, 30, 50)
```

مقدار `2` برای `step` یعنی پایتون هر دو عنصر یک بار عنصر بعدی را انتخاب می کند.

## ۶. برعکس کردن Tuple

یک `step` منفی به ما اجازه می دهد از انتهای Tuple به سمت ابتدای آن حرکت کنیم.

یکی از ساده ترین روش ها برای برعکس کردن Tuple این است:

```python
numbers = (10, 20, 30, 40, 50)

reversed_numbers = numbers[::-1]

print(reversed_numbers)
```

خروجی:

```text
(50, 40, 30, 20, 10)
```

در اینجا:

```text
start → خالی
stop  → خالی
step  → -1
```

بنابراین پایتون Tuple را از انتها به ابتدا پیمایش می کند.

## ۷. استفاده از اندیس های منفی در Slicing

می توانیم هنگام Slicing از اندیس های منفی نیز استفاده کنیم.

```python
fruits = ("Apple", "Banana", "Orange", "Mango", "Grape")

print(fruits[-4:-1])
```

خروجی:

```text
('Banana', 'Orange', 'Mango')
```

قوانین Slicing همچنان همان هستند. اندیس `stop` در نتیجه قرار نمی گیرد.

## ۸. قانون مهم

به خاطر داشته باشید:

```python
tuple[start:stop]
```

یعنی:

```text
start → شامل می شود
stop  → شامل نمی شود
```

همچنین:

```python
tuple[::-1]
```

یکی از روش های رایج برای برعکس کردن Tuple است.

## سوال ۱

```python
print(numbers[1:4])
```

## سوال ۲

تفاوت این دو چیست؟

```python
numbers[:3]
numbers[3:]
```

## سوال ۳

این کد چه چیزی چاپ می کند؟

```python
numbers = (10, 20, 30, 40, 50)

print(numbers[::-1])
```

## سوال مروری

چگونه می توانیم به یک عنصر مشخص از Tuple دسترسی داشته باشیم، محدوده ای از عناصر را انتخاب کنیم و کل Tuple را برعکس کنیم؟

# پاسخ ها

```text
(20, 30, 40)
```

## پاسخ ۲

`numbers[:3]` عناصر را از ابتدای Tuple تا قبل از اندیس `3` انتخاب می کند.

`numbers[3:]` عناصر را از اندیس `3` شروع می کند و تا انتهای Tuple ادامه می دهد.

## پاسخ ۳

```text

```

## پاسخ سوال مروری

برای دسترسی به یک عنصر از Indexing مانند `tuple[2]` استفاده می کنیم، برای انتخاب محدوده ای از عناصر از Slicing مانند `tuple[1:4]` و برای برعکس کردن Tuple از `tuple[::-1]` استفاده می کنیم.

# بخش ۵ — تغییر ناپذیری Tuple

## ۱. مفهوم اصلی Tuple

یکی از مهم ترین ویژگی های Tuple، **تغییر ناپذیری** آن است.

وقتی یک Tuple را می سازیم، ساختار آن دیگر قابل تغییر نیست.

برای مثال:

```python
student = ("Ali", 20, 18.5)

print(student)
```

این Tuple دارای سه عنصر است. بعد از ساخته شدن نمی توانیم مستقیماً یکی از عناصر آن را جایگزین کنیم.

```python
student = ("Ali", 20, 18.5)

student[1] = 21
```

این کد باعث ایجاد خطا می شود، زیرا Tuple تغییر ناپذیر است.

نکته مهم این نیست که مقادیر Tuple در هر شرایطی «کاملاً منجمد» هستند. مفهوم اصلی این است که **خود Tuple عملیاتی برای تغییر عناصر موجودش ارائه نمی کند**.

## ۲. مقایسه تغییر ناپذیری Tuple با تغییر پذیری List

برای درک بهتر تغییر ناپذیری، بهتر است Tuple را با List مقایسه کنیم.

List اجازه می دهد یک عنصر موجود را تغییر دهیم:

```python
student = ["Ali", 20, 18.5]

student[1] = 21

print(student)
```

خروجی:

```text
['Ali', 21, 18.5]
```

اما همین کار با Tuple امکان پذیر نیست:

```python
student = ("Ali", 20, 18.5)

student[1] = 21
```

تفاوت اصلی این دو به این شکل است:

```text
List  → عناصر قابل تغییر هستند
Tuple → عناصر قابل تغییر نیستند
```

این تفاوت یکی از دلایل اصلی وجود هم زمان List و Tuple در پایتون است.

## ۳. چرا تغییر ناپذیری مهم است؟

تغییر ناپذیری زمانی مفید است که بخواهیم داده ای را نمایش دهیم که باید ساختار آن ثابت باقی بماند.

برای مثال:

```python
point = (10, 20)
```

اگر این Tuple یک نقطه مشخص را نمایش دهد، ممکن است نخواهیم عناصر آن به صورت تصادفی تغییر کنند.

مثال دیگر می تواند یک تاریخ باشد:

```python
birthday = (15, 8, 2005)
```

این سه مقدار به عنوان یک گروه از اطلاعات در کنار یکدیگر قرار گرفته اند.

استفاده از Tuple می تواند این مفهوم را منتقل کند:

> این مقادیر به یکدیگر تعلق دارند و ساختار این گروه نباید تغییر کند.

## ۴. هنوز می توانیم یک Tuple جدید بسازیم

تغییر ناپذیری به این معنی نیست که دیگر هیچ وقت نمی توانیم Tuple متفاوتی داشته باشیم.

معنای آن این است که نمی توانیم Tuple موجود را در همان محل تغییر دهیم.

در عوض می توانیم یک Tuple جدید بسازیم:

```python
numbers = (10, 20, 30)

new_numbers = (100, 20, 30)

print(numbers)
print(new_numbers)
```

خروجی:

```text
(10, 20, 30)
(100, 20, 30)
```

Tuple اصلی بدون تغییر باقی می ماند.

این تفاوت را به خاطر داشته باشید:

```text
تغییر دادن Tuple موجود → مجاز نیست
ساختن یک Tuple جدید  → مجاز است
```

## ۵. عملیاتی که Tuple را تغییر نمی دهند

بسیاری از عملیات می توانند Tuple را بخوانند یا از آن استفاده کنند، بدون اینکه آن را تغییر دهند.

برای مثال:

```python
numbers = (10, 20, 30, 40)

print(numbers[1])
print(len(numbers))
print(20 in numbers)
```

خروجی:

```text
20
4
True
```

هیچ کدام از این عملیات Tuple را تغییر نمی دهند.

این تفاوت بین **خواندن داده** و **تغییر دادن داده** اهمیت زیادی دارد.

## ۶. متدهای تغییر دهنده List در Tuple وجود ندارند

List متدهایی مانند موارد زیر دارد:

```python
append()
remove()
sort()
```

این متدها می توانند List را تغییر دهند.

اما Tuple این متدهای تغییر دهنده را ندارد.

برای مثال:

```python
numbers = (10, 20, 30)

numbers.append(40)
```

این کد باعث ایجاد خطا می شود، زیرا Tuple متد `append()` ندارد.

به همین شکل:

```python
numbers = (10, 20, 30)

numbers.remove(20)
```

این کد نیز باعث ایجاد خطا می شود.

نبودن این متدها مستقیماً با تغییر ناپذیر بودن Tuple ارتباط دارد.

## ۷. تغییر ناپذیری و Slicing

Slicing باعث تغییر Tuple اصلی نمی شود.

در عوض یک Tuple جدید شامل عناصر انتخاب شده ایجاد می کند.

```python
numbers = (10, 20, 30, 40, 50)

part = numbers[1:4]

print(numbers)
print(part)
```

خروجی:

```text
(10, 20, 30, 40, 50)
(20, 30, 40)
```

Tuple اصلی بدون تغییر باقی می ماند.

این هم نمونه دیگری از تفاوت بین **ساختن یک مقدار جدید** و **تغییر دادن مقدار موجود** است.

## ۸. یک استثنای مهم: اشیای تغییر پذیر داخل Tuple

یک نکته عمیق تر وجود دارد که بهتر است از همین ابتدا با آن آشنا شویم.

خود Tuple تغییر ناپذیر است، اما یکی از عناصر آن می تواند یک شیء تغییر پذیر مانند List باشد.

برای مثال:

```python
data = ("Ali", [10, 20, 30])

data[1].append(40)

print(data)
```

خروجی:

```text
('Ali', [10, 20, 30, 40])
```

ما عنصر دوم Tuple را جایگزین نکردیم.

عنصر دوم همچنان همان شیء List است.

ما محتویات آن List را تغییر دادیم.

بنابراین باید بین این دو مفهوم تفاوت قائل شویم:

```text
ساختار Tuple تغییر ناپذیر است.
یک شیء ذخیره شده داخل Tuple ممکن است تغییر پذیر باشد.
```

این نکته برای برنامه نویسی پایتون بسیار مهم است، چون یک برداشت اشتباه رایج این است که:

> «اگر Tuple تغییر ناپذیر است، پس هیچ چیزی درون آن تحت هیچ شرایطی نمی تواند تغییر کند.»

این جمله همیشه درست نیست.

## ۹. مدل ذهنی مناسب

می توانیم تغییر ناپذیری Tuple را به شکل زیر تصور کنیم:

```text
Tuple
 ├── عنصر ۱
 ├── عنصر ۲
 └── عنصر ۳
```

Tuple اجازه نمی دهد عناصر آن را جایگزین، اضافه یا حذف کنیم.

اما اگر یکی از عناصر به یک شیء تغییر پذیر اشاره کند:

```text
Tuple
 ├── "Ali"
 └── List → [10, 20, 30]
```

خود List همچنان می تواند تغییر کند.

درک این موضوع باعث می شود مفاهیم پیشرفته تر پایتون را در آینده راحت تر یاد بگیرید.

# بخش ۶ — بررسی وجود یک عنصر در Tuple

## ۱. بررسی وجود یک عنصر

بعد از یادگیری روش دسترسی به عناصر Tuple، یکی از مهارت های مهم این است که بتوانیم بررسی کنیم آیا یک مقدار مشخص در Tuple وجود دارد یا خیر.

پایتون برای این کار از عملگر `in` استفاده می کند.

```python
fruits = ("Apple", "Banana", "Orange")

print("Banana" in fruits)
```

خروجی:

```text
True
```

چون `"Banana"` در Tuple وجود دارد، نتیجه `True` است.

اگر مقدار مورد نظر وجود نداشته باشد:

```python
fruits = ("Apple", "Banana", "Orange")

print("Mango" in fruits)
```

خروجی:

```text
False
```

عملگر `in` خود عنصر را برنمی گرداند. این عملگر وجود یک مقدار در Tuple را بررسی می کند و یک مقدار Boolean برمی گرداند:

```text
True  → عنصر وجود دارد
False → عنصر وجود ندارد
```

## ۲. استفاده از `not in`

می توانیم با استفاده از `not in` بررسی کنیم که یک عنصر در Tuple وجود **ندارد**.

```python
fruits = ("Apple", "Banana", "Orange")

print("Mango" not in fruits)
```

خروجی:

```text
True
```

چون `"Mango"` در Tuple وجود ندارد، نتیجه `True` است.

اگر عنصر وجود داشته باشد:

```python
print("Apple" not in fruits)
```

خروجی:

```text
False
```

## ۳. بررسی وجود عنصر بر اساس مقدار

وقتی از `in` استفاده می کنیم، پایتون بررسی می کند که مقدار مورد نظر در میان عناصر Tuple وجود دارد یا خیر.

برای مثال:

```python
numbers = (10, 20, 30, 40)

print(20 in numbers)
print(25 in numbers)
```

خروجی:

```text
True
False
```

در این بررسی، موقعیت عنصر اهمیتی ندارد.

ما می پرسیم:

> آیا این مقدار عضوی از Tuple است؟

نه اینکه:

> موقعیت این مقدار چیست؟

اگر به موقعیت عنصر نیاز داشته باشیم، در بخش بعدی از `index()` استفاده خواهیم کرد.

## ۴. استفاده از بررسی وجود عنصر در شرط

بررسی وجود عنصر زمانی کاربرد بیشتری پیدا می کند که آن را همراه با `if` استفاده کنیم.

```python
fruits = ("Apple", "Banana", "Orange")

if "Banana" in fruits:
    print("Banana is available.")
```

خروجی:

```text
Banana is available.
```

همچنین می توانیم حالت نبودن یک عنصر را نیز بررسی کنیم:

```python
fruits = ("Apple", "Banana", "Orange")

if "Mango" not in fruits:
    print("Mango is not available.")
```

خروجی:

```text
Mango is not available.
```

این ویژگی باعث می شود بررسی وجود عنصر در برنامه های واقعی کاربرد زیادی داشته باشد؛ چون برنامه می تواند بر اساس وجود یا نبودن یک مقدار تصمیم بگیرد.

## ۵. بررسی وجود عنصر و Stringها

عملگر `in` فقط برای اعداد نیست.

می توانیم آن را برای Stringها و انواع دیگر داده نیز استفاده کنیم، به شرطی که پایتون بتواند مقادیر را با یکدیگر مقایسه کند.

```python
names = ("Ali", "Sara", "Reza")

print("Sara" in names)
print("sara" in names)
```

خروجی:

```text
True
False
```

این مقایسه به حروف بزرگ و کوچک حساس است.

`"Sara"` و `"sara"` دو String متفاوت هستند.

## ۶. بررسی وجود عنصر در Tupleهای تو در تو

وقتی یک Tuple شامل Tuple دیگری باشد، `in` عناصر همان سطح را بررسی می کند.

```python
data = ("Ali", (10, 20, 30))

print(10 in data)
print((10, 20, 30) in data)
```

خروجی:

```text
False
True
```

چرا `10 in data` برابر `False` است؟

چون عناصر مستقیم `data` عبارت اند از:

```text
"Ali"
(10, 20, 30)
```

عدد `10` داخل Tuple داخلی قرار دارد، نه مستقیماً داخل `data`.

برای بررسی داخل Tuple داخلی، ابتدا باید به آن دسترسی پیدا کنیم:

```python
data = ("Ali", (10, 20, 30))

print(10 in data[1])
```

خروجی:

```text
True
```

این تفاوت هنگام کار با ساختارهای داده تو در تو اهمیت زیادی پیدا می کند.

## ۷. تفاوت Membership Checking و Indexing

Indexing و Membership Checking به دو سوال متفاوت پاسخ می دهند.

Indexing:

```python
fruits = ("Apple", "Banana", "Orange")

print(fruits[1])
```

خروجی:

```text
Banana
```

در اینجا موقعیت را می دانیم و می خواهیم مقدار موجود در آن موقعیت را پیدا کنیم.

Membership Checking:

```python
print("Banana" in fruits)
```

خروجی:

```text
True
```

در اینجا مقدار را داریم و می خواهیم بدانیم آیا در Tuple وجود دارد یا خیر.

یک مدل ذهنی مناسب:

```text
Indexing   → «چه مقداری در این موقعیت قرار دارد؟»
Membership → «آیا این مقدار وجود دارد؟»
```

درک این تفاوت باعث می شود برای هر مسئله از عملیات مناسب استفاده کنیم.

# بخش ۷ — طول و شمارش عناصر Tuple

## ۱. درک اندازه Tuple

یک Tuple می تواند تعداد مختلفی عنصر داشته باشد؛ از صفر عنصر گرفته تا تعداد زیادی عنصر.

برای اینکه بفهمیم یک Tuple چند عنصر دارد، از تابع `len()` استفاده می کنیم.

```python
fruits = ("Apple", "Banana", "Orange")

print(len(fruits))
```

خروجی:

```text
3
```

نتیجه `3` است، چون Tuple دارای سه عنصر است.

نکته مهم این است که `len()` تعداد **عناصر Tuple** را می شمارد، نه تعداد حروف موجود در این عناصر.

برای مثال:

```python
fruits = ("Apple", "Banana", "Orange")

print(len(fruits))
```

خروجی:

```text
3
```

تابع `len()` تعداد حروف تمام کلمات را محاسبه نمی کند.

## ۲. Tuple خالی و Tuple تک عنصری

`(10,)` یک Tuple است، اما `(10)` فقط مقدار عددی `10` است.

## ۳. ارتباط طول و اندیس ها

بین طول Tuple و اندیس های آن یک رابطه مهم وجود دارد.

```text
آخرین اندیس = طول Tuple - 1
```

در این مثال:

```text
طول = 5
آخرین اندیس = 4
```

این رابطه هنگام کار با مجموعه های داده ای که با اندیس کنترل می شوند بسیار مهم است.

## ۴. شمارش عناصر تکراری

`len()` تعداد کل عناصر Tuple را به ما می دهد.

اما گاهی می خواهیم بدانیم یک **مقدار مشخص** چند بار در Tuple تکرار شده است.

برای این کار Tuple دارای متد `count()` است.

```python

```

خروجی:

```text

```

عدد `10` سه بار در Tuple وجود دارد.

اگر مقدار مورد نظر اصلاً وجود نداشته باشد:

```python
numbers = (10, 20, 30)

print(numbers.count(50))
```

خروجی:

```text
0
```

## ۵. تفاوت `len()` و `count()`

این دو عملیات به دو سوال متفاوت پاسخ می دهند.

```python
numbers = (10, 20, 10, 30, 10)

print(len(numbers))
print(numbers.count(10))
```

خروجی:

```text
5
3
```

تفاوت آن ها:

```text
len(tuple)      → در مجموع چند عنصر وجود دارد؟
tuple.count(x)  → مقدار x چند بار وجود دارد؟
```

این تفاوت بسیار مهم است.

برای مثال:

```python
colors = ("Red", "Blue", "Red", "Green", "Red")
```

وقتی می نویسیم:

```python
len(colors)
```

در واقع می پرسیم:

اما وقتی می نویسیم:

```python
colors.count("Red")
```

می پرسیم:

> `"Red"` چند بار در Tuple تکرار شده است؟

## ۶. شمارش عناصر در داده های واقعی

فرض کنید نتیجه چند آزمون را در یک Tuple ذخیره کرده ایم:

## ۷. حساس بودن به حروف بزرگ و کوچک

`count()` مقادیر را بر اساس قوانین معمول مقایسه در پایتون بررسی می کند.

```python
numbers = (10, 20, 10, 30)
```

## ۹. یک مدل ذهنی مفید

می توانیم این عملیات را به عنوان سوال های متفاوتی درباره یک Tuple در نظر بگیریم:


وقتی این تفاوت را به خوبی درک کنیم، `len()` و `count()` به ابزارهای ساده اما کاربردی برای بررسی اطلاعات Tuple تبدیل می شوند.

# بخش ۸ — پیدا کردن موقعیت یک عنصر

## ۱. چرا به موقعیت عنصر نیاز داریم؟

در بخش قبلی یاد گرفتیم با استفاده از `in` بررسی کنیم که آیا یک عنصر در Tuple وجود دارد یا خیر.

برای مثال:

```python
fruits = ("Apple", "Banana", "Orange", "Mango")

print("Orange" in fruits)
```

خروجی:

```text
True
```

اما گاهی دانستن اینکه یک عنصر وجود دارد کافی نیست.

ممکن است لازم باشد بدانیم **آن عنصر در چه موقعیتی قرار دارد**.

برای این کار پایتون متد `index()` را در اختیار ما قرار می دهد.

## ۲. استفاده از `index()`

ساختار کلی:

```python
tuple.index(value)
```

برای مثال:

```python
fruits = ("Apple", "Banana", "Orange", "Mango")

print(fruits.index("Orange"))
```

خروجی:

```text
2
```

نتیجه `2` است، زیرا `"Orange"` در اندیس `2` قرار دارد.

به یاد داشته باشید که اندیس های Tuple از `0` شروع می شوند:

```text
Apple   → 0
Banana  → 1
Orange  → 2
Mango   → 3
```

## ۳. `index()` اولین رخداد را برمی گرداند

یک Tuple می تواند شامل مقادیر تکراری باشد.

برای مثال:

```python
fruits = ("Apple", "Banana", "Apple", "Orange", "Apple")

print(fruits.index("Apple"))
```

خروجی:

```text
0
```

در این Tuple سه مقدار `"Apple"` وجود دارد، اما `index()` فقط موقعیت **اولین رخداد** را برمی گرداند.

بنابراین:

```text
index()
↓
موقعیت اولین مقدار مطابق
```

این متد تمام موقعیت ها را برنمی گرداند.

## ۴. تفاوت `in` و `index()`

عملگر `in` و متد `index()` به یکدیگر مرتبط هستند، اما کاربرد متفاوتی دارند.

```python
fruits = ("Apple", "Banana", "Orange")

print("Banana" in fruits)
print(fruits.index("Banana"))
```

خروجی:

```text
True
1
```

عبارت اول می پرسد:

```text
آیا "Banana" وجود دارد؟
```

عبارت دوم می پرسد:

```text
"Banana" کجا قرار دارد؟
```

بنابراین:

```text
in       → بررسی وجود
index()  → پیدا کردن موقعیت
```

اگر فقط به یک پاسخ Boolean نیاز داشته باشیم، `in` کافی است.

اگر به موقعیت عنصر نیاز داشته باشیم، از `index()` استفاده می کنیم.

## ۵. اگر عنصر وجود نداشته باشد چه اتفاقی می افتد؟

اگر مقدار مورد نظر در Tuple وجود نداشته باشد، `index()` خطای `ValueError` ایجاد می کند.

برای مثال:

```python
fruits = ("Apple", "Banana", "Orange")

print(fruits.index("Mango"))
```

خروجی:

```text
ValueError: tuple.index(x): x not in tuple
```

این رفتار با `in` متفاوت است.

با `in`:

```python
print("Mango" in fruits)
```

خروجی:

```text
False
```

اما با `index()`:

```python
print(fruits.index("Mango"))
```

پایتون نمی تواند موقعیت معتبری برای `"Mango"` پیدا کند، بنابراین خطا ایجاد می شود.

در نتیجه، اگر مطمئن نیستیم که عنصر وجود دارد، بررسی Membership قبل از `index()` می تواند مفید باشد.

## ۶. ترکیب `in` و `index()`

می توانیم این دو عملیات را با یکدیگر ترکیب کنیم:

```python
fruits = ("Apple", "Banana", "Orange")

if "Banana" in fruits:
    print(fruits.index("Banana"))
```

خروجی:

```text
1
```

منطق کار:

```text
بررسی وجود مقدار
        ↓
      True
        ↓
پیدا کردن موقعیت
```

این الگو زمانی کاربردی است که ممکن است مقدار مورد نظر در داده وجود داشته باشد یا نداشته باشد.

## ۷. شروع جستجو از یک موقعیت مشخص

`index()` می تواند یک آرگومان `start` نیز دریافت کند.

```python
tuple.index(value, start)
```

برای مثال:

```python
fruits = ("Apple", "Banana", "Apple", "Orange", "Apple")

print(fruits.index("Apple", 1))
```

خروجی:

```text
2
```

چرا نتیجه `2` است؟

چون پایتون جستجو را از اندیس `1` شروع می کند.

اولین `"Apple"` در اندیس `0` قرار دارد، بنابراین نادیده گرفته می شود.

`"Apple"` بعدی در اندیس `2` قرار دارد.

می توانیم هم `start` و هم `stop` را مشخص کنیم:

```python
tuple.index(value, start, stop)
```

برای مثال:

```python
fruits = ("Apple", "Banana", "Apple", "Orange", "Apple")

print(fruits.index("Apple", 1, 4))
```

خروجی:

```text
2
```

جستجو از اندیس `1` شروع می شود و قبل از اندیس `4` متوقف می شود.

همان قانونی که در Slicing یاد گرفتیم در اینجا نیز برقرار است:

```text
start → شامل می شود
stop  → شامل نمی شود
```

## ۸. پیدا کردن موقعیت یک Tuple داخلی

`index()` عناصر همان Tupleای را جستجو می کند که متد روی آن فراخوانی شده است.

برای مثال:

```python
data = ("Ali", (10, 20, 30))

print(data.index((10, 20, 30)))
```

خروجی:

```text
1
```

Tuple داخلی `(10, 20, 30)` خودش یکی از عناصر `data` است، بنابراین `index()` می تواند آن را پیدا کند.

اما:

```python
print(data.index(10))
```

باعث ایجاد `ValueError` می شود.

چرا؟

چون `10` یک عنصر مستقیم `data` نیست.

ساختار داده این گونه است:

```text
data
├── "Ali"
└── (10, 20, 30)
      ├── 10
      ├── 20
      └── 30
```

برای جستجو در Tuple داخلی، ابتدا باید به آن دسترسی پیدا کنیم:

```python
data = ("Ali", (10, 20, 30))

print(data[1].index(10))
```

خروجی:

```text
0
```

این مثال یک اصل مهم را نشان می دهد:

> عملیات جستجو روی همان مجموعه ای انجام می شود که متد را روی آن فراخوانی کرده ایم.

## ۹. `index()` باعث تغییر Tuple نمی شود

`index()` فقط اطلاعات Tuple را جستجو می کند.

این متد Tuple را تغییر نمی دهد.

```python
numbers = (10, 20, 30)

position = numbers.index(20)

print(position)
print(numbers)
```

خروجی:

```text
1
(10, 20, 30)
```

Tuple بدون تغییر باقی می ماند.

این موضوع با مفهوم تغییر ناپذیری Tuple که در بخش های قبلی یاد گرفتیم کاملاً هماهنگ است.

## ۱۰. ارتباط `index()` با مفاهیم قبلی

در این مرحله چند ابزار مختلف برای بررسی Tuple در اختیار داریم:

```text
tuple[index]
    ↓
دسترسی به مقدار در یک موقعیت مشخص

value in tuple
    ↓
بررسی وجود یک مقدار

len(tuple)
    ↓
پیدا کردن تعداد کل عناصر

tuple.count(value)
    ↓
شمارش تعداد تکرار یک مقدار

tuple.index(value)
    ↓
پیدا کردن موقعیت اولین رخداد
```

هر کدام از این عملیات به سوال متفاوتی پاسخ می دهند.

یک برنامه نویس خوب فقط Syntax را حفظ نمی کند؛ بلکه باید بتواند تشخیص دهد برنامه دقیقاً باید به **چه سوالی درباره داده** پاسخ دهد.

# بخش ۹ — پیمایش Tupleها

## ۱. پیمایش یعنی چه؟

در بخش قبلی یاد گرفتیم چگونه با استفاده از `index()` موقعیت یک عنصر را پیدا کنیم.

اما بسیاری از مسائل به ما نیاز دارند که با **تمام عناصر** یک Tuple کار کنیم، نه فقط با یک عنصر مشخص.

برای مثال:

```python
fruits = ("Apple", "Banana", "Orange", "Mango")
```

اگر بخواهیم تمام میوه ها را پردازش کنیم، دسترسی دستی به تک تک اندیس ها تکراری خواهد بود:

```python
print(fruits[0])
print(fruits[1])
print(fruits[2])
print(fruits[3])
```

به جای این کار می توانیم Tuple را **پیمایش** کنیم.

پیمایش یعنی حرکت کردن روی عناصر یک مجموعه، یکی پس از دیگری، و انجام یک عملیات روی هر عنصر.

در پایتون رایج ترین روش پیمایش Tuple استفاده از حلقه `for` است.

## ۲. پیمایش با `for`

ساختار کلی:

```python
for element in tuple:
    # code
```

برای مثال:

```python
fruits = ("Apple", "Banana", "Orange", "Mango")

for fruit in fruits:
    print(fruit)
```

خروجی:

```text
Apple
Banana
Orange
Mango
```

پایتون در هر مرحله مقدار عنصر فعلی را به `fruit` می دهد.

به صورت مفهومی:

```text
تکرار اول → Apple
تکرار دوم → Banana
تکرار سوم → Orange
تکرار چهارم → Mango
```

حلقه تا زمانی ادامه پیدا می کند که تمام عناصر پردازش شوند.

## ۳. متغیر حلقه

متغیری که بعد از `for` قرار می گیرد، نماینده عنصر فعلی است.

برای مثال:

```python
numbers = (10, 20, 30)

for number in numbers:
    print(number)
```

خروجی:

```text
10
20
30
```

در هر تکرار:

```text
number = 10
number = 20
number = 30
```

نام این متغیر خاص نیست.

این کد نیز کاملاً معتبر است:

```python
for x in numbers:
    print(x)
```

اما معمولاً استفاده از نام های معنادار بهتر است:

```python
for number in numbers:
```

از:

```python
for x in numbers:
```

خواناتر است، مخصوصاً وقتی محتوای Tuple مشخص باشد.

## ۴. انجام عملیات هنگام پیمایش

پیمایش به ما اجازه می دهد هر مقدار را پردازش کنیم.

برای مثال:

```python
numbers = (10, 20, 30, 40)

for number in numbers:
    print(number * 2)
```

خروجی:

```text
20
40
60
80
```

Tuple اصلی تغییر نکرده است.

ما هر مقدار را خوانده ایم و عملیاتی روی آن انجام داده ایم.

این موضوع در مورد Tuple اهمیت ویژه ای دارد، زیرا عناصر Tuple را نمی توان مستقیماً جایگزین کرد.

## ۵. پیمایش همراه با شرط

می توانیم `for` را با `if` ترکیب کنیم.

برای مثال، فقط اعداد بزرگ تر یا مساوی `20` را چاپ کنیم:

```python
numbers = (10, 25, 15, 40, 30)

for number in numbers:
    if number > 20:
        print(number)
```

خروجی:

```text
25
40
30
```

الگوی کلی:

```text
پیمایش
   ↓
بررسی عنصر فعلی
   ↓
بررسی شرط
   ↓
انجام عملیات در صورت برقرار بودن شرط
```

این الگو در بسیاری از برنامه های پایتون استفاده می شود.

## ۶. پیمایش برای شمارش

می توانیم عناصری را که یک شرط مشخص دارند نیز شمارش کنیم.

```python
numbers = (10, 25, 15, 40, 30)

count = 0

for number in numbers:
    if number > 20:
        count += 1

print(count)
```

خروجی:

```text
3
```

Tuple یک بار پیمایش می شود.

هر بار که عددی بزرگ تر از `20` پیدا شود، مقدار `count` یک واحد افزایش پیدا می کند.

توجه کنید که این کار با `count()` متفاوت است:

```python
numbers.count(10)
```

متد `count()` تعداد رخدادهای **یک مقدار مشخص** را می شمارد.

اما حلقه می تواند عناصر را بر اساس **یک شرط** شمارش کند.

## ۷. پیمایش همراه با اندیس با `enumerate()`

گاهی به خود عنصر و اندیس آن به صورت هم زمان نیاز داریم.

پایتون برای این کار `enumerate()` را در اختیار ما قرار می دهد.

```python
fruits = ("Apple", "Banana", "Orange")

for index, fruit in enumerate(fruits):
    print(index, fruit)
```

خروجی:

```text
0 Apple
1 Banana
2 Orange
```

در هر تکرار دو مقدار دریافت می کنیم:

```text
index → موقعیت
fruit → مقدار
```

این روش معمولاً از ایجاد و افزایش دستی یک متغیر برای اندیس خواناتر است.

برای مثال، به جای:

```python
index = 0

for fruit in fruits:
    print(index, fruit)
    index += 1
```

می توانیم بنویسیم:

```python
for index, fruit in enumerate(fruits):
    print(index, fruit)
```

## ۸. شروع `enumerate()` از یک عدد دیگر

به صورت پیش فرض، `enumerate()` شمارش را از `0` شروع می کند.

می توانیم نقطه شروع را با `start` تغییر دهیم:

```python
fruits = ("Apple", "Banana", "Orange")

for index, fruit in enumerate(fruits, start=1):
    print(index, fruit)
```

خروجی:

```text
1 Apple
2 Banana
3 Orange
```

این کار فقط عددی را که `enumerate()` در اختیار ما قرار می دهد تغییر می دهد.

اندیس واقعی Tuple تغییر نمی کند.

اندیس های واقعی همچنان این ها هستند:

```text
Apple   → 0
Banana  → 1
Orange  → 2
```

## ۹. پیمایش به صورت معکوس

گاهی لازم است عناصر را از آخرین عنصر به سمت اولین عنصر پردازش کنیم.

برای این کار می توانیم از `reversed()` استفاده کنیم:

```python
numbers = (10, 20, 30, 40)

for number in reversed(numbers):
    print(number)
```

خروجی:

```text
40
30
20
10
```

این کار ترتیب پیمایش را تغییر می دهد، اما Tuple اصلی را تغییر نمی دهد.

Tuple همچنان:

```python
(10, 20, 30, 40)
```

باقی می ماند.

## ۱۰. پیمایش Tupleهای تو در تو

یک Tuple می تواند شامل Tupleهای دیگری باشد.

برای مثال:

```python
students = (
    ("Ali", 18),
    ("Sara", 20),
    ("Reza", 17)
)
```

می توانیم Tuple بیرونی را پیمایش کنیم:

```python
for student in students:
    print(student)
```

خروجی:

```text
('Ali', 18)
('Sara', 20)
('Reza', 17)
```

اما چون هر عنصر خودش یک Tuple است، می توانیم هنگام پیمایش آن را Unpack کنیم:

```python
for name, score in students:
    print(name, score)
```

خروجی:

```text
Ali 18
Sara 20
Reza 17
```

این روش زمانی بسیار کاربردی است که Tuple نماینده یک داده ساختار یافته باشد.

## ۱۱. پیمایش باعث تغییر Tuple نمی شود

یک اشتباه رایج این است که تصور کنیم تغییر متغیر حلقه باعث تغییر Tuple می شود.

برای مثال:

```python
numbers = (10, 20, 30)

for number in numbers:
    number = number * 2

print(numbers)
```

خروجی:

```text
(10, 20, 30)
```

دستور:

```python
number = number * 2
```

فقط متغیر حلقه را تغییر می دهد.

این دستور عنصر متناظر داخل Tuple را جایگزین نمی کند.

این رفتار با تغییر ناپذیر بودن Tuple سازگار است.

## ۱۲. اهمیت پیمایش

پیمایش فقط یک روش ساده برای چاپ کردن مقادیر نیست.

با استفاده از پیمایش می توانیم الگوریتم هایی بسازیم که روی مجموعه ای از داده ها کار کنند.

برای مثال:

```text
خواندن هر عنصر
      ↓
بررسی مقدار آن
      ↓
مقایسه با یک شرط
      ↓
شمارش یا پردازش
      ↓
تولید نتیجه
```

به همین دلیل پیمایش یکی از سازوکارهای بنیادی برای پردازش مجموعه ها در پایتون است.

سوال مهم فقط این نیست که:

> «چگونه Tuple را پیمایش کنم؟»

بلکه باید بپرسیم:

> «برنامه من هنگام رسیدن به هر عنصر باید چه کاری انجام دهد؟»

این نوع نگاه باعث می شود حلقه از یک Syntax ساده به یک ابزار الگوریتمی تبدیل شود.

```python
for value1, value2 in tuple:
```

# بخش ۱۰ — ترکیب و تکرار Tupleها

## ۱. ترکیب Tupleها با `+`

می توانیم Tupleها را با استفاده از عملگر `+` با یکدیگر ترکیب کنیم.

به این عملیات **Concatenation** یا الحاق گفته می شود.

برای مثال:

```python
first = (1, 2, 3)
second = (4, 5, 6)

result = first + second

print(result)
```

خروجی:

```text
(1, 2, 3, 4, 5, 6)
```

عناصر `second` بعد از عناصر `first` قرار می گیرند.

Tupleهای اصلی تغییر نمی کنند:

```python
print(first)
print(second)
```

خروجی:

```text
(1, 2, 3)
(4, 5, 6)
```

عملگر `+` یک **Tuple جدید** ایجاد می کند.

## ۲. ترکیب بیشتر از دو Tuple

می توانیم چند Tuple را در یک عبارت با یکدیگر ترکیب کنیم.

```python
a = (1, 2)
b = (3, 4)
c = (5, 6)

result = a + b + c

print(result)
```

خروجی:

```text
(1, 2, 3, 4, 5, 6)
```

پایتون عملیات Concatenation را از چپ به راست انجام می دهد.

به صورت مفهومی:

```text
(1, 2)
   +
(3, 4)
   ↓
(1, 2, 3, 4)
   +
(5, 6)
   ↓
(1, 2, 3, 4, 5, 6)
```

## ۳. ترکیب Tupleهایی با انواع داده متفاوت

Tuple می تواند شامل انواع داده مختلف باشد، بنابراین Tupleهای ترکیب شده نیز می توانند انواع داده متفاوتی داشته باشند.

```python
numbers = (10, 20)
words = ("Python", "Tuple")

result = numbers + words

print(result)
```

خروجی:

```text
(10, 20, 'Python', 'Tuple')
```

عناصر به یک نوع مشترک تبدیل نمی شوند.

هر عنصر نوع اصلی خودش را حفظ می کند.

## ۴. Concatenation باعث تغییر Tupleهای اصلی نمی شود

از آنجا که Tuple تغییر ناپذیر است، عملیات `+` عناصر را به یک Tuple موجود اضافه نمی کند.

برای مثال:

```python
numbers = (1, 2, 3)

numbers = numbers + (4, 5)

print(numbers)
```

خروجی:

```text
(1, 2, 3, 4, 5)
```

ممکن است در نگاه اول به نظر برسد که عناصر به Tuple قبلی اضافه شده اند.

اما از نظر مفهومی، یک Tuple جدید ساخته شده و متغیر `numbers` به Tuple جدید ارجاع داده شده است.

Tuple قبلی خودش تغییر نکرده است.

این تفاوت زمانی اهمیت بیشتری پیدا می کند که چند متغیر به یک Tuple اشاره کنند.

## ۵. تکرار Tuple با `*`

از عملگر `*` می توان برای تکرار یک Tuple استفاده کرد.

برای مثال:

```python
numbers = (1, 2, 3)

print(numbers * 3)
```

خروجی:

```text
(1, 2, 3, 1, 2, 3, 1, 2, 3)
```

کل توالی سه بار تکرار می شود.

عدد سمت راست مشخص می کند که چند بار Tuple تکرار شود.

```python
(1, 2) * 2
```

نتیجه:

```text
(1, 2, 1, 2)
```

و:

```python
(1, 2) * 4
```

نتیجه:

```text
(1, 2, 1, 2, 1, 2, 1, 2)
```

## ۶. تکرار صفر باره

می توانیم Tuple را صفر بار تکرار کنیم.

```python
numbers = (1, 2, 3)

print(numbers * 0)
```

خروجی:

```text
()
```

نتیجه یک Tuple خالی است.

این موضوع نشان می دهد که نتیجه عملیات تکرار بر اساس تعداد دفعات درخواستی ساخته می شود.

## ۷. تکرار با عدد منفی

اگر تعداد تکرار منفی باشد نیز نتیجه یک Tuple خالی است.

```python
numbers = (1, 2, 3)

print(numbers * -2)
```

خروجی:

```text
()
```

پایتون نمی تواند یک Tuple را تعداد منفی بار تکرار کند.

بنابراین نتیجه را به صورت Tuple خالی تولید می کند.

## ۸. ترکیب و تکرار هم زمان

می توانیم Concatenation و Repetition را با یکدیگر ترکیب کنیم.

```python
a = (1, 2)
b = (3, 4)

result = (a + b) * 2

print(result)
```

خروجی:

```text
(1, 2, 3, 4, 1, 2, 3, 4)
```

ابتدا:

```python
a + b
```

نتیجه می دهد:

```text
(1, 2, 3, 4)
```

سپس:

```python
* 2
```

آن Tuple را تکرار می کند.

بنابراین ترتیب عملیات اهمیت دارد.

## ۹. تقدم عملگرها و پرانتز

هنگام ترکیب چند عملیات، استفاده از پرانتز می تواند ساختار مورد نظر را مشخص کند.

این دو عبارت را مقایسه کنید:

```python
a = (1, 2)
b = (3, 4)

print(a + b * 2)
```

و:

```python
print((a + b) * 2)
```

در عبارت اول، ابتدا `b` تکرار می شود:

```text
(1, 2, 3, 4, 3, 4)
```

در عبارت دوم، ابتدا `a` و `b` با هم ترکیب می شوند و سپس نتیجه تکرار می شود:

```text
(1, 2, 3, 4, 1, 2, 3, 4)
```

این یک نکته مهم است:

> پرانتز می تواند ساختار یک عبارت مربوط به Tuple را تغییر دهد.

## ۱۰. ترکیب Tuple با یک عنصر

یک اشتباه رایج این است که هنگام ترکیب یک عنصر، فراموش کنیم که برای ساختن Tuple تک عنصری به کاما نیاز داریم.

این کد اشتباه است:

```python
numbers = (1, 2, 3)

result = numbers + (4)

print(result)
```

کد باعث ایجاد `TypeError` می شود.

چرا؟

چون:

```python
(4)
```

فقط عدد صحیح `4` است، نه یک Tuple.

برای ساختن Tuple تک عنصری باید از کامای انتهایی استفاده کنیم:

```python
(4,)
```

بنابراین:

```python
numbers = (1, 2, 3)

result = numbers + (4,)

print(result)
```

خروجی:

```text
(1, 2, 3, 4)
```

این یکی از مهم ترین نکات هنگام کار با Tupleهای تک عنصری است.

## ۱۱. ترکیب Tuple با List

عملگر `+` به نوع های سازگار برای Concatenation نیاز دارد.

برای مثال:

```python
numbers = (1, 2, 3)
values = [4, 5, 6]

print(numbers + values)
```

این کد باعث ایجاد `TypeError` می شود.

Tuple و List را نمی توان مستقیماً با `+` با یکدیگر ترکیب کرد.

اگر بخواهیم آن ها را ترکیب کنیم، ابتدا باید یکی را به نوع دیگری تبدیل کنیم:

```python
numbers = (1, 2, 3)
values = [4, 5, 6]

result = numbers + tuple(values)

print(result)
```

خروجی:

```text
(1, 2, 3, 4, 5, 6)
```

این موضوع تفاوت میان List و Tuple را نیز نشان می دهد.

## ۱۲. کاربرد عملی ترکیب Tupleها

ترکیب Tupleها می تواند هنگام ساختن مجموعه های ثابت بزرگ تر از چند مجموعه کوچک تر مفید باشد.

برای مثال:

```python
morning = ("Breakfast", "Study")
evening = ("Exercise", "Reading")

day = morning + evening

print(day)
```

خروجی:

```text
('Breakfast', 'Study', 'Exercise', 'Reading')
```

همچنین تکرار می تواند برای ساختن یک ساختار ثابت و تکراری مفید باشد:

```python
pattern = ("A", "B")

print(pattern * 3)
```

خروجی:

```text
('A', 'B', 'A', 'B', 'A', 'B')
```

نکته اصلی این است که هر دو عملیات، یعنی `+` و `*`، یک **Tuple جدید** ایجاد می کنند و Tuple موجود را تغییر نمی دهند.

```python
numbers = (1, 2, 3)
```

`(4)` فقط عدد `4` است، در حالی که `(4,)` به دلیل وجود کامای انتهایی یک Tuple تک عنصری است.

# بخش ۱۱ — تبدیل بین List و Tuple

List و Tuple هر دو از انواع داده ترتیبی در پایتون هستند، اما ویژگی های متفاوتی دارند.

List تغییر پذیر است، در حالی که Tuple تغییر ناپذیر است.

گاهی داده را به صورت List دریافت می کنیم اما می خواهیم با آن به شکل Tuple کار کنیم، یا برعکس.

پایتون با استفاده از `list()` و `tuple()` این تبدیل را به سادگی امکان پذیر می کند.

## ۱. تبدیل List به Tuple

تابع `tuple()` می تواند یک Iterable را به Tuple تبدیل کند.

برای مثال:

```python
fruits = ["Apple", "Banana", "Orange"]

fruits_tuple = tuple(fruits)

print(fruits_tuple)
```

خروجی:

```text
('Apple', 'Banana', 'Orange')
```

List اصلی همچنان List باقی می ماند:

```python
print(fruits)
print(type(fruits_tuple))
```

خروجی:

```text
['Apple', 'Banana', 'Orange']
<class 'tuple'>
```

این تبدیل یک Tuple جدید با همان عناصر ایجاد می کند.

## ۲. تبدیل Tuple به List

تابع `list()` تبدیل برعکس را انجام می دهد.

```python
fruits = ("Apple", "Banana", "Orange")

fruits_list = list(fruits)

print(fruits_list)
```

خروجی:

```text
['Apple', 'Banana', 'Orange']
```

حالا `fruits_list` یک List است:

```python
print(type(fruits_list))
```

خروجی:

```text
<class 'list'>
```

Tuple اصلی همچنان بدون تغییر باقی می ماند.

## ۳. چرا Tuple را به List تبدیل کنیم؟

یکی از دلایل مهم این است که List تغییر پذیر است.

فرض کنید:

```python
fruits = ("Apple", "Banana", "Orange")
```

نمی توانیم مستقیماً یک عنصر را تغییر دهیم:

```python
fruits[1] = "Mango"
```

این کد باعث ایجاد `TypeError` می شود.

اگر لازم باشد داده را تغییر دهیم، می توانیم Tuple را موقتاً به List تبدیل کنیم:

```python
fruits = ("Apple", "Banana", "Orange")

fruits_list = list(fruits)
fruits_list[1] = "Mango"

print(fruits_list)
```

خروجی:

```text
['Apple', 'Mango', 'Orange']
```

اگر بخواهیم نتیجه نهایی دوباره Tuple باشد:

```python
fruits = ("Apple", "Banana", "Orange")

fruits_list = list(fruits)
fruits_list[1] = "Mango"

fruits = tuple(fruits_list)

print(fruits)
```

خروجی:

```text
('Apple', 'Mango', 'Orange')
```

این الگو زمانی کاربردی است که بخواهیم ساختار نهایی داده Tuple باشد، اما در طول پردازش به قابلیت تغییر پذیری List نیاز داشته باشیم.

## ۴. چرا List را به Tuple تبدیل کنیم؟

حالت برعکس نیز بسیار رایج است.

فرض کنید:

```python
coordinates = [10, 20]
```

اگر این مقادیر یک جفت مختصات ثابت را نشان دهند، می توانیم آن ها را به Tuple تبدیل کنیم:

```python
coordinates = tuple(coordinates)

print(coordinates)
```

خروجی:

```text
(10, 20)
```

Tuple نشان می دهد که این مجموعه قرار است به عنوان یک توالی ثابت مورد استفاده قرار گیرد.

این موضوع فقط مربوط به Syntax نیست.

انتخاب بین List و Tuple می تواند هدف و نحوه استفاده از داده را نیز مشخص کند.

## ۵. تبدیل به صورت خودکار متغیر اصلی را تغییر نمی دهد

فراخوانی `tuple()` یا `list()` به تنهایی متغیر اصلی را تغییر نمی دهد.

برای مثال:

```python
numbers = [1, 2, 3]

tuple(numbers)

print(numbers)
```

خروجی:

```text
[1, 2, 3]
```

List همچنان List باقی مانده است، زیرا نتیجه تبدیل را ذخیره نکرده ایم.

باید نتیجه را به یک متغیر اختصاص دهیم:

```python
numbers = [1, 2, 3]

numbers = tuple(numbers)

print(numbers)
```

خروجی:

```text
(1, 2, 3)
```

همین اصل در جهت برعکس نیز برقرار است:

```python
numbers = (1, 2, 3)

numbers = list(numbers)

print(numbers)
```

خروجی:

```text
[1, 2, 3]
```

توابع تبدیل، یک شیء ترتیبی جدید برمی گردانند.

## ۶. تبدیل String

String نیز یک Iterable است، بنابراین می توان آن را به List یا Tuple تبدیل کرد.

برای مثال:

```python
word = "Python"

print(list(word))
```

خروجی:

```text
['P', 'y', 't', 'h', 'o', 'n']
```

و:

```python
word = "Python"

print(tuple(word))
```

خروجی:

```text
('P', 'y', 't', 'h', 'o', 'n')
```

هر کاراکتر به یک عنصر مستقل تبدیل می شود.

این مثال نشان می دهد که `list()` و `tuple()` فقط برای تبدیل بین List و Tuple نیستند و می توانند بسیاری از Iterableها را به این دو نوع داده تبدیل کنند.

## ۷. تبدیل `range`

یک شیء `range` نیز قابل تبدیل است.

```python
numbers = range(1, 5)

print(tuple(numbers))
```

خروجی:

```text
(1, 2, 3, 4)
```

و:

```python
numbers = range(1, 5)

print(list(numbers))
```

خروجی:

```text
[1, 2, 3, 4]
```

خود `range` نه List است و نه Tuple، اما مقادیر آن می توانند در قالب هر کدام از این دو ساختار قرار بگیرند.

## ۸. تبدیل List و Tuple نوع عناصر را تغییر نمی دهد

وقتی یک List را به Tuple تبدیل می کنیم، پایتون **نوع Container** را تغییر می دهد، نه نوع تک تک عناصر را.

برای مثال:

```python
data = [10, "Python", True]

result = tuple(data)

print(result)
```

خروجی:

```text
(10, 'Python', True)
```

عناصر همچنان:

```text
10       → int
"Python" → str
True     → bool
```

هستند.

فقط Container بیرونی از List به Tuple تغییر کرده است.

## ۹. ساختارهای تو در تو

تبدیل روی ساختارهای تو در تو نیز کار می کند، اما تمام Containerهای داخلی را به صورت خودکار تبدیل نمی کند.

برای مثال:

```python
data = [(1, 2), (3, 4)]

result = tuple(data)

print(result)
```

خروجی:

```text
((1, 2), (3, 4))
```

List بیرونی به Tuple تبدیل شده است.

Tupleهای داخلی همچنان Tuple باقی مانده اند.

مثال دیگر:

```python
data = [(1, 2), [3, 4]]

result = tuple(data)

print(result)
```

خروجی:

```text
((1, 2), [3, 4])
```

Container بیرونی تغییر کرده، اما List داخلی همچنان List باقی مانده است.

این نکته بسیار مهم است:

> `list()` و `tuple()` شیئی را که مستقیماً دریافت می کنند تبدیل می کنند؛ آن ها تمام Containerهای تو در تو را به صورت بازگشتی تبدیل نمی کنند.

## ۱۰. انتخاب Container مناسب

می توانیم به صورت ساده این گونه به List و Tuple نگاه کنیم:

```text
List
↓
داده ممکن است تغییر کند

Tuple
↓
داده باید ثابت باقی بماند
```

برای مثال:

```python
shopping_cart = ["Apple", "Milk", "Bread"]
```

محتوای سبد خرید ممکن است تغییر کند، بنابراین List انتخاب مناسبی است.

اما:

```python
point = (10, 20)
```

یک جفت مختصات را می توان به شکل Tuple نمایش داد، زمانی که آن را به عنوان یک مجموعه ثابت از مقادیر در نظر می گیریم.

انتخاب Container باید بر اساس نقش داده باشد، نه صرفاً سلیقه شخصی.

## ۱۱. تبدیل رفت و برگشتی

هر زمان لازم باشد می توانیم بین دو نوع حرکت کنیم.

```python
data = [1, 2, 3]

data = tuple(data)
print(data)

data = list(data)
print(data)
```

خروجی:

```text
(1, 2, 3)
[1, 2, 3]
```

این به معنی یکسان بودن رفتار List و Tuple نیست.

آن ها همچنان ویژگی های متفاوتی دارند.

تبدیل فقط به ما اجازه می دهد زمانی که نیازهای برنامه تغییر می کند، Container مناسب را انتخاب کنیم.

## ۱۲. مفهوم عمیق تر

نکته مهم فقط حفظ کردن این Syntaxها نیست:

```python
tuple(data)
```

و:

```python
list(data)
```

مفهوم عمیق تر این است که بدانیم **چرا** یک تبدیل لازم است.

ممکن است تبدیل کنیم:

```text
List → Tuple
```

وقتی می خواهیم یک توالی ثابت و تغییر ناپذیر داشته باشیم.

یا:

```text
Tuple → List
```

وقتی لازم است توالی را تغییر دهیم.

بعد از پردازش نیز می توانیم آن را دوباره تبدیل کنیم:

```text
Tuple
  ↓
List
  ↓
تغییر
  ↓
Tuple
```

به این ترتیب می توانیم داده ای را که در حالت نهایی باید تغییر ناپذیر باشد، در طول پردازش به صورت موقت تغییر پذیر کنیم.

# بخش ۱۲ — باز کردن Tuple (Tuple Unpacking)

Tuple Unpacking روشی ساده و کاربردی برای برداشتن عناصر یک Tuple و اختصاص دادن آن ها به چند متغیر جداگانه است.

به جای اینکه هر عنصر را جداگانه با اندیس دریافت کنیم:

```python
person = ("Ali", 20)

name = person[0]
age = person[1]

print(name)
print(age)
```

می توانیم Tuple را مستقیماً باز کنیم:

```python
person = ("Ali", 20)

name, age = person

print(name)
print(age)
```

خروجی:

```text
Ali
20
```

مقدارها از چپ به راست به متغیرها اختصاص داده می شوند:

```text
"Ali" → name
20    → age
```

## ۱. تعداد متغیرها باید با تعداد عناصر هماهنگ باشد

در حالت معمول، تعداد متغیرهای سمت چپ باید با تعداد عناصر Tuple برابر باشد.

این کد درست است:

```python
numbers = (10, 20, 30)

a, b, c = numbers

print(a)
print(b)
print(c)
```

خروجی:

```text
10
20
30
```

اما این کد درست نیست:

```python
numbers = (10, 20, 30)

a, b = numbers
```

پایتون خطای زیر را ایجاد می کند:

```text
ValueError: too many values to unpack
```

چون سه مقدار داریم، اما فقط دو متغیر وجود دارد.

حالت برعکس نیز خطا ایجاد می کند:

```python
numbers = (10, 20)

a, b, c = numbers
```

خروجی:

```text
ValueError: not enough values to unpack
```

چون فقط دو مقدار داریم، اما سه متغیر در سمت چپ قرار گرفته اند.

## ۲. Unpacking فقط مخصوص Tuple نیست

Unpacking با سایر Iterableها نیز کار می کند.

برای مثال:

```python
numbers = [10, 20, 30]

a, b, c = numbers

print(a, b, c)
```

خروجی:

```text
10 20 30
```

با String نیز می توانیم این کار را انجام دهیم:

```python
word = "ABC"

a, b, c = word

print(a)
print(b)
print(c)
```

خروجی:

```text
A
B
C
```

ایده اصلی این است که پایتون عناصر تولید شده توسط Iterable را از چپ به راست به متغیرهای سمت چپ اختصاص می دهد.

## ۳. جابه جا کردن مقدار دو متغیر

یکی از کاربردهای مهم Tuple Unpacking، جابه جا کردن مقدار دو متغیر است.

بدون Unpacking ممکن است به یک متغیر موقت نیاز داشته باشیم:

```python
a = 10
b = 20

temp = a
a = b
b = temp

print(a)
print(b)
```

خروجی:

```text
20
10
```

اما پایتون اجازه می دهد این کار را ساده تر انجام دهیم:

```python
a = 10
b = 20

a, b = b, a

print(a)
print(b)
```

خروجی:

```text
20
10
```

به صورت مفهومی، پایتون ابتدا مقدارهای سمت راست را در نظر می گیرد و سپس آن ها را به متغیرهای سمت چپ اختصاص می دهد:

```text
b, a
 ↓
20, 10
 ↓
a, b
```

این یکی از الگوهای کاربردی پایتون است.

## ۴. باز کردن Tupleهای تو در تو

می توانیم ساختارهای تو در تو را نیز Unpack کنیم.

برای مثال:

```python
student = ("Ali", (18, 20, 19))

name, scores = student

print(name)
print(scores)
```

خروجی:

```text
Ali
(18, 20, 19)
```

حتی می توانیم یک مرحله عمیق تر شویم:

```python
student = ("Ali", (18, 20, 19))

name, (score1, score2, score3) = student

print(name)
print(score1)
print(score2)
print(score3)
```

خروجی:

```text
Ali
18
20
19
```

ساختار متغیرهای سمت چپ می تواند با ساختار داده سمت راست هماهنگ باشد.

## ۵. استفاده از Unpacking در حلقه `for`

Tuple Unpacking هنگام پیمایش مجموعه ای از Tupleهای کوچک تر بسیار کاربردی است.

برای مثال:

```python
students = (
    ("Ali", 18),
    ("Sara", 20),
    ("Reza", 17)
)

for name, score in students:
    print(name, score)
```

خروجی:

```text
Ali 18
Sara 20
Reza 17
```

در هر تکرار، Tuple داخلی باز می شود.

به صورت مفهومی:

```text
("Ali", 18)  → name = "Ali",  score = 18
("Sara", 20) → name = "Sara", score = 20
("Reza", 17) → name = "Reza", score = 17
```

این کار استفاده از داده های ساختار یافته را بسیار ساده تر می کند.

## ۶. استفاده از `_` برای مقدارهای غیرضروری

گاهی چند مقدار دریافت می کنیم اما به همه آن ها نیاز نداریم.

برای مثال:

```python
person = ("Ali", 20, "Baku")

name, _, city = person

print(name)
print(city)
```

خروجی:

```text
Ali
Baku
```

استفاده از `_` یک قرارداد رایج است که به برنامه نویسان دیگر می گوید:

> «عمداً این مقدار را نادیده گرفته ام.»

از نظر پایتون `_` همچنان یک نام متغیر معمولی است، اما در این نوع کدها به عنوان نشانه ای برای مقدار غیرضروری استفاده می شود.

## ۷. استفاده از `*` برای دریافت مقدارهای باقی مانده

گاهی تعداد دقیق مقدارهایی که باید در متغیرهای جداگانه قرار بگیرند مشخص نیست.

پایتون برای این حالت Extended Unpacking را با `*` فراهم می کند.

برای مثال:

```python
numbers = (10, 20, 30, 40, 50)

first, *middle, last = numbers

print(first)
print(middle)
print(last)
```

خروجی:

```text
10
[20, 30, 40]
50
```

یک نکته مهم این است که:

`middle` یک **List** است، حتی اگر `numbers` یک Tuple باشد.

متغیری که `*` دارد، مقدارهای باقی مانده را در یک List جمع می کند.

می توانیم `*` را در موقعیت دیگری نیز قرار دهیم:

```python
numbers = (10, 20, 30, 40, 50)

first, second, *rest = numbers

print(first)
print(second)
print(rest)
```

خروجی:

```text
10
20
[30, 40, 50]
```

## ۸. Extended Unpacking بدون مقدار باقی مانده

متغیر دارای `*` حتی می تواند هیچ مقداری دریافت نکند.

```python
numbers = (10, 20)

first, *rest = numbers

print(first)
print(rest)
```

خروجی:

```text
10
[20]
```

اما:

```python
numbers = (10,)

first, *rest = numbers

print(first)
print(rest)
```

خروجی:

```text
10
[]
```

متغیر دارای `*` همیشه مقدارهای باقی مانده را به صورت List دریافت می کند.

## ۹. چرا Unpacking مهم است؟

Tuple Unpacking کمک می کند Syntax برنامه با ساختار داده هماهنگ شود.

به جای:

```python
student = ("Ali", 18)

name = student[0]
score = student[1]
```

می توانیم بنویسیم:

```python
name, score = student
```

این روش هنگام کار با داده های ساختار یافته اهمیت بیشتری پیدا می کند:

```python
students = (
    ("Ali", 18),
    ("Sara", 20),
    ("Reza", 17)
)

for name, score in students:
    print(f"{name}: {score}")
```

خروجی:

```text
Ali: 18
Sara: 20
Reza: 17
```

کد کوتاه تر شده و ارتباط میان ساختار داده و متغیرها نیز واضح تر است.

## ۱۰. قانون اصلی

مهم ترین قانون این بخش:

> ساختار سمت چپ باید با مقدارهای سمت راست سازگار باشد.

برای Unpacking ساده:

```python
a, b, c = (10, 20, 30)
```

سه متغیر و سه مقدار داریم.

برای Unpacking تو در تو:

```python
name, (x, y) = ("Ali", (10, 20))
```

ساختار دو طرف با یکدیگر هماهنگ است.

برای Extended Unpacking:

```python
first, *middle, last = (10, 20, 30, 40)
```

متغیر دارای `*` اجازه می دهد قسمت میانی شامل چند مقدار باشد.

درک این ساختار مهم تر از حفظ کردن مثال های جداگانه است.

# سوال ها

## سوال ۱

این کد چه چیزی چاپ می کند؟

```python
person = ("Ali", 20)

name, age = person

print(name)
print(age)
```

## سوال ۲

در این کد چه اتفاقی می افتد و چرا؟

```python
numbers = (10, 20, 30)

a, b = numbers
```

## سوال ۳

این کد چه چیزی چاپ می کند؟

```python
numbers = (10, 20, 30, 40, 50)

first, *middle, last = numbers

print(first)
print(middle)
print(last)
```

## سوال مروری

Tuple Unpacking را توضیح دهید و بگویید چگونه می توان از آن با Tupleهای تو در تو، حلقه `for`، مقدارهای نادیده گرفته شده با `_` و Extended Unpacking با `*` استفاده کرد.

# پاسخ ها

## پاسخ ۱

```text
Ali
20
```

## پاسخ ۲

پایتون خطای زیر را ایجاد می کند:

```text
ValueError: too many values to unpack
```

سه مقدار داریم، اما فقط دو متغیر داریم.

## پاسخ ۳

```text
10
[20, 30, 40]
50
```

متغیر `middle` مقدارهای باقی مانده را به صورت یک List دریافت می کند.

## پاسخ سوال مروری

Tuple Unpacking عناصر یک Iterable را از چپ به راست به چند متغیر اختصاص می دهد.

می توان از آن برای باز کردن ساختارهای تو در تو استفاده کرد:

```python
name, (x, y) = ("Ali", (10, 20))
```

همچنین در حلقه های `for` کاربرد دارد:

```python
for name, score in students:
```

قرارداد `_` برای مقدارهایی که عمداً به آن ها نیاز نداریم استفاده می شود و `*` می تواند چند مقدار باقی مانده را در یک List جمع کند.

# بخش ۱۳ — Tupleهای تو در تو

یک Tuple می تواند به عنوان عناصر خود، Tupleهای دیگری داشته باشد.

به این ساختار **Nested Tuple** یا Tuple تو در تو گفته می شود.

Tupleهای تو در تو به ما اجازه می دهند داده هایی با بیش از یک سطح ساختار را نمایش دهیم، در حالی که ساختار بیرونی همچنان تغییر ناپذیر باقی می ماند.

برای مثال:

```python
student = ("Ali", (18, 20, 19))

print(student)
```

خروجی:

```text
('Ali', (18, 20, 19))
```

در اینجا `student` شامل دو عنصر است:

```text
"Ali"
(18, 20, 19)
```

عنصر دوم خودش یک Tuple است.

## ۱. دسترسی به Tuple داخلی

می توانیم با استفاده از چند اندیس به مقدارهای موجود در سطوح مختلف دسترسی پیدا کنیم.

```python
student = ("Ali", (18, 20, 19))

print(student[0])
print(student[1])
```

خروجی:

```text
Ali
(18, 20, 19)
```

برای دسترسی به یک نمره مشخص:

```python
print(student[1][0])
```

خروجی:

```text
18
```

اولین `[1]` به Tuple داخلی دسترسی پیدا می کند.

دومین `[0]` اولین عنصر Tuple داخلی را انتخاب می کند.

به صورت مفهومی:

```text
student
   ↓
[1]
   ↓
(18, 20, 19)
   ↓
[0]
   ↓
18
```

## ۲. بیشتر از دو سطح

Nested Tuple فقط به دو سطح محدود نمی شود.

برای مثال:

```python
data = (
    "Python",
    (
        "Tuples",
        (
            "Nested",
            "Data"
        )
    )
)

print(data[1][1][0])
```

خروجی:

```text
Nested
```

برای رسیدن به هر سطح، یک عملیات Indexing دیگر لازم است.

اگرچه پایتون اجازه چنین ساختاری را می دهد، ساختارهای بسیار عمیق می توانند درک و نگهداری کد را دشوار کنند.

در سطح مقدماتی بهتر است ساختار را تا حد امکان متناسب با نیاز مسئله ساده نگه داریم.

## ۳. Nested Tuple برای نگهداری چند Record

Nested Tuple زمانی کاربردی تر می شود که هر Tuple داخلی نماینده یک Record باشد.

برای مثال:

```python
students = (
    ("Ali", 18),
    ("Sara", 20),
    ("Reza", 17)
)

print(students)
```

خروجی:

```text
(('Ali', 18), ('Sara', 20), ('Reza', 17))
```

Tuple بیرونی شامل سه Tuple داخلی است.

هر Tuple داخلی نماینده یک دانش آموز است:

```text
("Ali", 18)
("Sara", 20)
("Reza", 17)
```

این روش یک راه ساده برای نمایش داده های ساختار یافته است.

## ۴. دسترسی به یک Record

می توانیم یک Tuple داخلی را به صورت کامل دریافت کنیم:

```python
students = (
    ("Ali", 18),
    ("Sara", 20),
    ("Reza", 17)
)

print(students[1])
```

خروجی:

```text
('Sara', 20)
```

سپس می توانیم به یک مقدار داخل آن Record دسترسی پیدا کنیم:

```python
print(students[1][0])
```

خروجی:

```text
Sara
```

و:

```python
print(students[1][1])
```

خروجی:

```text
20
```

در اینجا اندیس اول Record را مشخص می کند و اندیس دوم یک فیلد داخل آن Record را مشخص می کند.

## ۵. پیمایش Nested Tupleها

به جای دسترسی دستی به هر Record، می توانیم از حلقه استفاده کنیم.

```python
students = (
    ("Ali", 18),
    ("Sara", 20),
    ("Reza", 17)
)

for student in students:
    print(student)
```

خروجی:

```text
('Ali', 18)
('Sara', 20)
('Reza', 17)
```

چون هر Tuple داخلی شامل دو مقدار است، می توانیم از Tuple Unpacking استفاده کنیم:

```python
for name, score in students:
    print(name, score)
```

خروجی:

```text
Ali 18
Sara 20
Reza 17
```

این یکی از کاربردهای بسیار عملی Nested Tuple است.

## ۶. Nested Tuple با انواع داده متفاوت

عناصر یک Nested Tuple لازم نیست همگی از یک نوع باشند.

برای مثال:

```python
person = (
    "Ali",
    20,
    ("Baku", "Azerbaijan")
)

print(person)
```

خروجی:

```text
('Ali', 20, ('Baku', 'Azerbaijan'))
```

در اینجا:

```text
"Ali"                  → str
20                     → int
("Baku", "Azerbaijan") → Tuple
```

این ویژگی اجازه می دهد اطلاعات مرتبط را در یک ساختار منظم کنار هم قرار دهیم.

## ۷. Nested Tuple و تغییر ناپذیری

Tuple بیرونی تغییر ناپذیر است.

برای مثال:

```python
student = ("Ali", (18, 20, 19))

student[0] = "Sara"
```

این کد باعث ایجاد:

```text
TypeError
```

می شود، زیرا تلاش می کنیم یکی از عناصر Tuple بیرونی را جایگزین کنیم.

اما هنگام قرار دادن اشیای تغییر پذیر در داخل Tuple، یک نکته مهم وجود دارد.

برای مثال:

```python
data = ("Ali", [18, 20, 19])

data[1][0] = 100

print(data)
```

خروجی:

```text
('Ali', [100, 20, 19])
```

Tuple بیرونی تغییر نکرده است.

در واقع List موجود درون Tuple را تغییر داده ایم.

بنابراین باید این نکته مهم را به خاطر داشته باشیم:

> تغییر ناپذیر بودن Tuple به خود Tuple و ارجاع های آن به عناصر مربوط می شود؛ این ویژگی به صورت خودکار اشیای تغییر پذیر موجود درون Tuple را تغییر ناپذیر نمی کند.

این تفاوت هنگام کار با Listها و سایر اشیای تغییر پذیر اهمیت زیادی پیدا می کند.

## ۸. Nested Tuple و `len()`

تابع `len()` تعداد عناصر را در همان سطحی که روی آن اعمال شده است شمارش می کند.

برای مثال:

```python
students = (
    ("Ali", 18),
    ("Sara", 20),
    ("Reza", 17)
)

print(len(students))
```

خروجی:

```text
3
```

چون Tuple بیرونی سه عنصر دارد.

اما:

```python
print(len(students[0]))
```

خروجی:

```text
2
```

چون اولین Tuple داخلی دو عنصر دارد.

بنابراین `len()` به صورت خودکار تمام مقدارهای موجود در همه سطوح را شمارش نمی کند.

این تابع روی شیئی که مستقیماً به آن داده می شود عمل می کند.

## ۹. Nested Tuple و Slicing

Slicing را نیز می توان در سطوح مختلف انجام داد.

برای مثال:

```python
students = (
    ("Ali", 18),
    ("Sara", 20),
    ("Reza", 17),
    ("Mina", 19)
)

print(students[1:3])
```

خروجی:

```text
(('Sara', 20), ('Reza', 17))
```

این Slice روی Tuple بیرونی اعمال شده است.

می توانیم روی Tuple داخلی نیز Slice انجام دهیم:

```python
student = ("Ali", 18, 20, 19)

print(student[1:3])
```

خروجی:

```text
(18, 20)
```

نکته مهم این است که Slicing در سطح همان شیئی انجام می شود که روی آن Indexing کرده ایم.

## ۱۰. Nested Tuple و Unpacking

Nested Tupleها را می توان بر اساس ساختارشان Unpack کرد.

برای مثال:

```python
student = ("Ali", (18, 20, 19))

name, (score1, score2, score3) = student

print(name)
print(score1)
print(score2)
print(score3)
```

خروجی:

```text
Ali
18
20
19
```

ساختار سمت چپ با ساختار سمت راست هماهنگ است.

این موضوع ترکیبی از دو مبحث قبلی، یعنی Tuple Unpacking و Nested Tuple است.

## ۱۱. تغییر داده داخل Nested Tuple

از آنجا که Tuple تغییر ناپذیر است، نمی توانیم مستقیماً یکی از عناصر آن را جایگزین کنیم.

برای مثال:

```python
student = ("Ali", (18, 20, 19))

student[1] = (20, 20, 20)
```

این کد باعث ایجاد `TypeError` می شود.

اگر Tuple متفاوتی لازم داشته باشیم، باید یک Tuple جدید بسازیم:

```python
student = ("Ali", (18, 20, 19))

student = ("Ali", (20, 20, 20))

print(student)
```

خروجی:

```text
('Ali', (20, 20, 20))
```

Tuple قبلی تغییر نکرده است.

یک Tuple جدید ساخته شده و به `student` اختصاص داده شده است.

## ۱۲. چه زمانی Nested Tuple مفید است؟

Nested Tuple زمانی مناسب است که داده به صورت طبیعی چند سطح داشته باشد و بخواهیم این ساختار ثابت باقی بماند.

برای مثال، چند نقطه مختصاتی:

```python
points = (
    (10, 20),
    (30, 40),
    (50, 60)
)
```

هر Tuple داخلی یک نقطه را نشان می دهد.

یا مجموعه ای ساده از اطلاعات دانش آموزان:

```python
students = (
    ("Ali", 18),
    ("Sara", 20),
    ("Reza", 17)
)
```

Tuple بیرونی مجموعه را نشان می دهد.

هر Tuple داخلی یک Record را نشان می دهد.

خود ساختار به ما نشان می دهد که داده چگونه سازمان دهی شده است.

## پاسخ سوال مروری

Nested Tuple یک Tuple است که شامل Tupleهای دیگری می شود. برای دسترسی به هر سطح از ساختار می توان از Indexing بیشتر استفاده کرد.

برای مثال:

```python
data[1][0]
```

دو عملیات Indexing انجام می دهد تا به یک مقدار درون Tuple داخلی برسد.

البته اگر یک شیء تغییر پذیر مانند List داخل Tuple قرار داشته باشد، خود آن شیء داخلی همچنان می تواند تغییر کند.

# بخش ۱۴ — مرور نهایی Tupleها

در این بخش تمام مفاهیم مقدماتی Tuple که تا اینجا یاد گرفته ایم را مرور می کنیم.

هدف این بخش معرفی یک مفهوم بزرگ جدید نیست؛ بلکه قرار است تمام مفاهیم را کنار یکدیگر قرار دهیم تا مطمئن شویم مهارت های پایه کار با Tuple را به صورت یکپارچه یاد گرفته ایم.

---

## ۱. Tuple چیست؟

Tuple یک مجموعه مرتب از مقدارها است.

```python
numbers = (10, 20, 30)
```

یک Tuple:

- ترتیب عناصر را حفظ می کند؛
- می تواند شامل انواع داده متفاوت باشد؛
- از Indexing و Slicing پشتیبانی می کند؛
- تغییر ناپذیر است.

برای مثال:

```python
person = ("Ali", 20, True)

print(person)
```

خروجی:

```text
('Ali', 20, True)
```

---

## ۲. ساختن Tuple

یکی از روش های معمول ساخت Tuple استفاده از پرانتز است:

```python
numbers = (10, 20, 30)
```

Tuple خالی:

```python
empty = ()
```

Tuple تک عنصری به کامای انتهایی نیاز دارد:

```python
single = (10,)
```

این یک Tuple نیست:

```python
single = (10)
```

در اینجا `single` فقط یک عدد صحیح است.

---

## ۳. دسترسی به عناصر

عناصر Tuple با استفاده از Indexing قابل دسترسی هستند.

```python
numbers = (10, 20, 30, 40)

print(numbers[0])
print(numbers[2])
```

خروجی:

```text
10
30
```

می توانیم از اندیس های منفی نیز برای دسترسی از انتهای Tuple استفاده کنیم:

```python
print(numbers[-1])
```

خروجی:

```text
40
```

اولین عنصر اندیس `0` دارد، نه `1`.

---

## ۴. Slicing در Tuple

با Slicing می توانیم محدوده ای از عناصر را دریافت کنیم.

```python
numbers = (10, 20, 30, 40, 50)

print(numbers[1:4])
```

خروجی:

```text
(20, 30, 40)
```

اندیس شروع شامل نتیجه می شود، اما اندیس پایان شامل نتیجه نمی شود.

می توانیم از Step نیز استفاده کنیم:

```python
print(numbers[::2])
```

خروجی:

```text
(10, 30, 50)
```

Slicing یک Tuple دیگر ایجاد می کند.

---

## ۵. تغییر ناپذیری Tuple

نمی توانیم عناصر موجود در Tuple را جایگزین کنیم.

این کد معتبر نیست:

```python
numbers = (10, 20, 30)

numbers[1] = 100
```

پایتون خطای:

```text
TypeError
```

ایجاد می کند.

اما می توانیم یک Tuple کاملاً جدید به متغیر اختصاص دهیم:

```python
numbers = (10, 20, 30)

numbers = (10, 100, 30)

print(numbers)
```

خروجی:

```text
(10, 100, 30)
```

Tuple قبلی تغییر نکرده است.

یک Tuple جدید ساخته شده است.

---

## ۶. بررسی وجود یک عنصر

با عملگر `in` می توانیم بررسی کنیم که آیا یک مقدار در Tuple وجود دارد یا خیر.

```python
numbers = (10, 20, 30)

print(20 in numbers)
print(50 in numbers)
```

خروجی:

```text
True
False
```

عملگر مقابل آن `not in` است:

```python
print(50 not in numbers)
```

خروجی:

```text
True
```

این روش زمانی کاربردی است که فقط بخواهیم بدانیم یک مقدار وجود دارد یا خیر.

## ۷. طول Tuple

```python
numbers = (10, 20, 30, 40)
```

```python
data = (
    ("Ali", 18),

print(len(data))
```

```text
2
```

Tuple بیرونی دو عنصر دارد.

```python
numbers = (10, 20, 30)
```

## ۱۰. پیمایش Tuple

با حلقه `for` می توانیم تمام عناصر Tuple را بررسی کنیم.

```python
numbers = (10, 20, 30)

for number in numbers:
    print(number)
```

خروجی:

```text
10
20
30
```

پیمایش زمانی کاربرد دارد که بخواهیم عملیاتی را روی تک تک عناصر انجام دهیم.

برای مثال:

```python
numbers = (10, 20, 30)

for number in numbers:
    print(number * 2)
```

خروجی:

```text
20
40
60
```

## ۱۱. ترکیب Tupleها

```python
a = (1, 2)
```

## ۱۲. تکرار Tuple

```python
numbers = (1, 2)
```

## ۱۳. تبدیل بین List و Tuple

با `tuple()` می توان List را به Tuple تبدیل کرد:

```python
numbers = [10, 20, 30]

numbers = tuple(numbers)

print(numbers)
```

خروجی:

```text
(10, 20, 30)
```

با `list()` می توان Tuple را به List تبدیل کرد:

```python
numbers = (10, 20, 30)

numbers = list(numbers)

print(numbers)
```

خروجی:

```text
[10, 20, 30]
```

این تبدیل زمانی مفید است که نیازهای رفتاری داده تغییر کند.

برای مثال ممکن است موقتاً Tuple را به List تبدیل کنیم تا بتوانیم عناصر آن را تغییر دهیم.

## ۱۴. Tuple Unpacking

Unpacking عناصر Tuple را به متغیرهای جداگانه اختصاص می دهد.

```python
person = ("Ali", 20)

name, age = person

print(name)
print(age)
```

خروجی:

```text
Ali
20
```

در حالت معمول تعداد متغیرها باید با تعداد مقدارها هماهنگ باشد.

پایتون Extended Unpacking را نیز پشتیبانی می کند:

```python
numbers = (10, 20, 30, 40)

first, *middle, last = numbers

print(first)
print(middle)
print(last)
```

خروجی:

```text
10
[20, 30]
40
```

متغیر دارای `*` مقدارهای باقی مانده را در یک List جمع می کند.

---

## ۱۵. Nested Tuple

یک Tuple می تواند شامل Tupleهای دیگری باشد.

```python
students = (
    ("Ali", 18),
    ("Sara", 20),
    ("Reza", 17)
)
```

می توانیم با استفاده از چند Indexing به مقدارهای داخلی دسترسی پیدا کنیم:

```python
print(students[1][0])
```

خروجی:

```text
Sara
```

Nested Tuple زمانی مفید است که داده به صورت طبیعی چند سطح داشته باشد.

همچنین می توانیم آن را Unpack کنیم:

```python
for name, score in students:
    print(name, score)
```

خروجی:

```text
Ali 18
Sara 20
Reza 17
```

## ۱۶. ارتباط این مفاهیم با یکدیگر

مفاهیم مختلف زمانی ارزش بیشتری پیدا می کنند که در کنار یکدیگر استفاده شوند.

این داده را در نظر بگیرید:

```python
students = (
    ("Ali", 18),
    ("Sara", 20),
    ("Reza", 17),
    ("Mina", 19)
)
```

می توانیم بررسی کنیم که یک Record کامل وجود دارد یا خیر:

```python
print(("Sara", 20) in students)
```

خروجی:

```text
True
```

می توانیم تعداد Recordها را پیدا کنیم:

```python
print(len(students))
```

خروجی:

```text
4
```

می توانیم به یک Record مشخص دسترسی پیدا کنیم:

```python
print(students[2])
```

خروجی:

```text
('Reza', 17)
```

می توانیم به یک فیلد دسترسی پیدا کنیم:

```python
print(students[2][1])
```

خروجی:

```text
17
```

می توانیم تمام Recordها را پیمایش کنیم:

```python
for name, score in students:
    print(name, score)
```

خروجی:

```text
Ali 18
Sara 20
Reza 17
Mina 19
```

اینجاست که مفاهیم مختلف Tuple از حالت دستورات جداگانه خارج می شوند و به یک مهارت یکپارچه تبدیل می شوند.

## ۱۷. یک مثال کامل مقدماتی

یک مجموعه کوچک از اطلاعات ثابت دانش آموزان را در نظر بگیرید:

```python
students = (
    ("Ali", 18),
    ("Sara", 20),
    ("Reza", 17),
    ("Mina", 19)
)

print("Number of students:", len(students))

print("Sara exists:", ("Sara", 20) in students)

for name, score in students:
    print(name, score)
```

خروجی:

```text
Number of students: 4
Sara exists: True
Ali 18
Sara 20
Reza 17
Mina 19
```

در این مثال کوچک از مفاهیم زیر استفاده شده است:

- ساخت Tuple؛
- Nested Tuple؛
- `len()`؛
- Membership Testing؛
- پیمایش با `for`؛
- Tuple Unpacking.

هدف مرور این است که ببینیم این مفاهیم چگونه در کنار یکدیگر کار می کنند، نه اینکه آن ها را فقط به صورت دستورات جداگانه حفظ کنیم.

## ۱۸. انتخاب بین List و Tuple

در سطح مقدماتی می توانیم یک قانون ساده داشته باشیم:

```text
آیا مجموعه باید تغییر کند؟
        ↓
      List

آیا مجموعه باید ثابت بماند؟
        ↓
      Tuple
```

برای مثال:

```python
shopping_cart = ["Milk", "Bread", "Eggs"]
```

محتوای سبد خرید می تواند تغییر کند، بنابراین List انتخاب مناسبی است.

اما:

```python
point = (10, 20)
```

می تواند به صورت Tuple نمایش داده شود، زمانی که این جفت مقدار را یک مجموعه ثابت در نظر می گیریم.

این قانون برای تمام برنامه ها مطلق نیست، اما نقطه شروع مناسبی برای انتخاب بین List و Tuple است.

## ۱۹. اشتباه های رایج

### اشتباه ۱ — فراموش کردن کاما

```python
value = (10)
```

این یک عدد صحیح است، نه Tuple.

روش صحیح:

```python
value = (10,)
```

### اشتباه ۲ — تلاش برای تغییر Tuple

```python
numbers = (1, 2, 3)

numbers[0] = 100
```

این کد باعث `TypeError` می شود.

### اشتباه ۳ — فرض کردن اینکه `index()` همیشه بدون خطا جستجو می کند

```python
numbers = (1, 2, 3)

numbers.index(10)
```

این کد باعث `ValueError` می شود.

در صورت نیاز می توانیم ابتدا وجود مقدار را بررسی کنیم:

```python
if 10 in numbers:
    print(numbers.index(10))
```

### اشتباه ۴ — اشتباه گرفتن سطح بیرونی و داخلی

در این ساختار:

```python
data = (
    ("A", 10),
    ("B", 20)
)
```

این دو عبارت متفاوت هستند:

```python
data[0]
```

و:

```python
data[0][0]
```

اولی کل Tuple داخلی را برمی گرداند:

```text
('A', 10)
```

دومی:

```text
A
```

را برمی گرداند.

درک سطحی که یک عملیات روی آن انجام می شود، هنگام کار با Nested Tupleها بسیار مهم است.

# سوال های نهایی

## سوال ۱

این کد چه چیزی چاپ می کند؟

```python
numbers = (10, 20, 10, 30)

print(numbers.count(10))
print(numbers.index(30))
print(len(numbers))
```

## سوال ۲

این کد چه چیزی چاپ می کند؟

```python
data = (

    ("Reza", 17)

print(data[1][0])
print(data[2][1])
```

## سوال ۳

تفاوت این دو عملیات چیست؟

```python
numbers[1]
numbers[1:2]
```

فرض کنید:

```python

```

## سوال ۴

این کد چه چیزی چاپ می کند؟

```python
numbers = (1, 2, 3, 4)

a, *b, c = numbers

print(a)
print(b)
print(c)
```

## سوال ۵

توضیح دهید چرا این کد معتبر است:

```python
data = ("Ali", [18, 20, 19])

data[1][0] = 100
```

با وجود اینکه Tuple تغییر ناپذیر است.

## سوال چالشی

با استفاده از تمام چیزهایی که تاکنون درباره Tuple یاد گرفته اید، برنامه ای بنویسید که چند Record دانش آموز را در یک Nested Tuple ذخیره کند.

برنامه باید:

1. تعداد دانش آموزان را چاپ کند؛
2. وجود یک Record مشخص را بررسی کند؛
3. تمام Recordها را پیمایش کند؛
4. نام و نمره هر دانش آموز را چاپ کند؛
5. موقعیت یک Record را پیدا کند؛
6. تعداد تکرار یک Record مشخص را شمارش کند.

Tuple اصلی نباید تغییر کند.
