## ۱. Tuple چیست؟

**Tuple** یکی از انواع داده در پایتون است که می تواند چند مقدار را در کنار یکدیگر نگه دارد.

Tuple شبیه List است، اما یک تفاوت مهم دارد:

```text
List  → قابل تغییر است
Tuple → بعد از ساخت قابل تغییر نیست
```

برای مثال:

```python
fruits = ("Apple", "Banana", "Orange")

print(fruits)
```

خروجی:

```text
('Apple', 'Banana', 'Orange')
```

مقادیر مختلف درون یک Tuple قرار گرفته اند.

## ۲. ساخت Tuple

برای ساخت Tuple معمولاً عناصر را داخل پرانتز `()` قرار می دهیم.

```python
numbers = (10, 20, 30, 40)

print(numbers)
```

خروجی:

```text
(10, 20, 30, 40)
```

یک Tuple می تواند شامل انواع مختلف داده نیز باشد:

```python
student = ("Ali", 20, 18.5)

print(student)
```

خروجی:

```text
('Ali', 20, 18.5)
```

## ۳. تفاوت Tuple و List

برای ساخت List از براکت استفاده می کنیم:

```python
fruits = ["Apple", "Banana", "Orange"]
```

برای ساخت Tuple معمولاً از پرانتز استفاده می کنیم:

```python
fruits = ("Apple", "Banana", "Orange")
```

تفاوت مهم این دو در تغییرپذیری آن هاست.

List قابل تغییر است:

```python
fruits = ["Apple", "Banana", "Orange"]

fruits[0] = "Mango"

print(fruits)
```

خروجی:

```text
['Mango', 'Banana', 'Orange']
```

اما Tuple را نمی توان به این شکل تغییر داد:

```python
fruits = ("Apple", "Banana", "Orange")

fruits[0] = "Mango"
```

پایتون خطا ایجاد می کند، چون عناصر Tuple بعد از ساخته شدن قابل تغییر نیستند.

## ۴. چه زمانی از Tuple استفاده می کنیم؟

Tuple زمانی کاربردی است که چند مقدار داشته باشیم و بخواهیم این مقادیر ثابت باقی بمانند.

برای مثال:

```python
location = (51.5074, -0.1278)

print(location)
```

خروجی:

```text
(51.5074, -0.1278)
```

این Tuple می تواند یک جفت مقدار ثابت را نمایش دهد.

مثال دیگر:

```python
birthday = (15, 8, 2005)

print(birthday)
```

خروجی:

```text
(15, 8, 2005)
```

## ۵. یک نکته مهم برای شروع

Tuple فقط به معنی «List با پرانتز» نیست.

مفهوم اصلی Tuple این است که **تغییرناپذیر** است.

یعنی بعد از ساخته شدن Tuple نمی توانیم مستقیماً عناصر آن را تغییر دهیم، اضافه کنیم یا حذف کنیم.

در بخش های بعدی این مفهوم را دقیق تر بررسی می کنیم.

فعلاً به خاطر داشته باشید:

```text
List  → قابل تغییر
Tuple → تغییرناپذیر
```
