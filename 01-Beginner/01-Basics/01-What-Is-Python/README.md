# Part 1 — Introduction

## What is Programming?

Computers are incredibly fast, but they are not intelligent.

They cannot think, make decisions, or solve problems on their own.

Instead, they follow instructions given by humans.

Programming is the process of writing those instructions.

A program is simply a collection of instructions that tells a computer what to do.

For example:

- Display a message.
- Calculate a number.
- Save information.
- Open a website.
- Play a video.

Everything a computer does begins with instructions written by a programmer.

---

## What is Python?

Python is a **high-level, general-purpose programming language** created to make programming easier, more readable, and more enjoyable.

Unlike low-level languages that are closer to machine code, Python allows developers to write code that looks much more like human language.

For example:

```python
print("Hello, World!")
```

Even if you've never programmed before, you can probably guess what this code does.

That's one of Python's greatest strengths.

Its syntax is clean, simple, and easy to understand.

Python allows programmers to focus on solving problems instead of worrying about complicated language rules.

---

# Lesson Summary

- A program is a collection of instructions.
- Python is a programming language.
- Python was designed to be simple and readable.
- Python allows beginners to focus on problem-solving instead of complex syntax.

# Part 2 — Why Learn Python?

Have you ever wondered why Python is one of the most popular programming languages in the world?

The answer lies in its simplicity, versatility, and the enormous community that supports it.

Today, Python is used by millions of developers, students, researchers, and companies across the globe.

Whether you want to build websites, analyze data, create artificial intelligence systems, or automate repetitive tasks, Python provides the tools to achieve your goals.

---

## Why is Python Popular?

Python became popular because it removes many of the difficulties beginners usually face when learning programming.

Instead of spending time understanding complicated syntax, you can focus on learning programming concepts and solving problems.

This makes Python one of the best languages for learning computer science and software development.

Python has a simple and readable syntax.

Many Python programs look almost like plain English, making them easier to understand.

---

### 2. Easy to Read

Python emphasizes clean and organized code.

Readable code is easier to maintain, debug, and improve.

### 3. Cross-Platform

Python programs can run on:

without major changes.

### 4. Huge Standard Library

Python comes with hundreds of built-in modules that help you perform common tasks without writing everything from scratch.

Millions of developers use Python.

Every programming language has a story, and every story has a creator.

Python was created by a Dutch software engineer named **Guido van Rossum**.

In the late 1980s, Guido was working on different software projects and noticed that many programming languages were either too difficult to learn or too complicated for everyday programming.

He believed programming should be simple, readable, and enjoyable.

With that vision in mind, he started working on a new programming language during the Christmas holidays of **1989**.

That small personal project eventually became one of the most influential programming languages in the world.

---

## Why Was Python Created?

Guido wanted a language that would allow programmers to:

- Write less code.
- Read code more easily.
- Focus on solving problems instead of language complexity.
- Increase productivity.

Instead of creating a language only for experts, he wanted to build one that everyone could learn and use.

Today, those original goals are still reflected in Python's philosophy.

---

## Why Is It Called "Python"?

Many people think Python was named after the snake.

Interestingly, that is **not true**.

Guido was a fan of a British comedy television show called **Monty Python's Flying Circus**.

When choosing a name for his new language, he wanted something short, unique, and memorable.

He chose **Python** as a tribute to that comedy group.

This is also why the Python community often uses humor in its documentation and examples.

---

## The Evolution of Python

Python has continuously evolved since its first public release.

Some important milestones include:

| Year | Event |
|------|-------|
| 1989 | Development of Python begins |
| 1991 | First public release |
| 2000 | Python 2.0 released |
| 2008 | Python 3.0 released |
| Today | Python is one of the world's most popular programming languages |

Each new version introduced improvements, better performance, and new features.

---

## Python 2 vs Python 3

For many years, Python existed in two major versions:

- Python 2
- Python 3

Although Python 2 was extremely popular, it had several design limitations.

Instead of keeping those limitations forever, the Python developers decided to redesign parts of the language and released **Python 3**.

Because of these improvements:

- Python 2 officially reached its end of life in **2020**.
- Modern development uses **Python 3**.
- Every new learner should start directly with Python 3.

Throughout this roadmap, every example and every project will use **Python 3**.
