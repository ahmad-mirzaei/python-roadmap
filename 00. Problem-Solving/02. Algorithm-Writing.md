## 📖 Overview

In the previous lesson, you learned what an algorithm is and why it is important.

Now it's time to learn **how to write one**.

Writing an algorithm is one of the most valuable skills for every programmer. A well-written algorithm makes coding easier, reduces mistakes, and helps you solve problems more effectively.

In this lesson, you'll learn a simple method for writing clear and logical algorithms that you will use throughout this course.

---

## 🎯 Learning Objectives

After completing this lesson, you will be able to:

- Write simple and readable algorithms.
- Analyze a problem before writing code.
- Identify the input and output of a problem.
- Break a problem into smaller steps.
- Avoid common mistakes when writing algorithms.

---

## ❓ Why Should We Write Algorithms?

Imagine you're building a house.

Would you start laying bricks without a blueprint?

Probably not.

You would first create a plan.

Programming works the same way.

Writing code without an algorithm is like building a house without a blueprint.

An algorithm helps you:

- Understand the problem.
- Organize your thoughts.
- Find the easiest solution.
- Write cleaner code.
- Reduce bugs.

Professional programmers rarely start coding immediately.

They first understand the problem, design a solution, and only then write code.

> [!IMPORTANT]
> Good code starts with a good algorithm.

## 🧠 The Problem-Solving Process

Throughout this roadmap, we will solve every programming problem using the same four-step process.

```text
Problem
   │
   ▼
Input / Output
   │
   ▼
Algorithm
   │
   ▼
Python Code
```

This process helps you think before you code.

Let's look at each step.

---

### Step 1 — Understand the Problem

Read the problem carefully.

Ask yourself:

- What is the goal?
- What should the program do?
- What information is available?

If you don't understand the problem, don't write any code yet.

---

### Step 2 — Identify the Input and Output

Every programming problem has an input and an output.

**Input**

The information the program receives.

**Output**

The result the program should produce.

Example:

**Problem**

Calculate the average of three numbers.

| Item | Value |
|------|-------|
| Input | Three numbers |
| Output | Average |

This simple table makes the problem much easier to understand.

---

### Step 3 — Write the Algorithm

Now write the solution step by step.

Don't think about Python.

Think only about the solution.

Example:

1. Read the first number.
2. Read the second number.
3. Read the third number.
4. Add the numbers.
5. Divide the sum by 3.
6. Display the average.

Notice that these steps describe the solution, not the programming language.

---

### Step 4 — Convert the Algorithm into Code

Only after completing the algorithm should you start writing Python.

Because the difficult part has already been done.

Programming is simply translating your algorithm into code.

> [!TIP]
> If writing the code feels difficult, the real problem is usually the algorithm—not Python.
