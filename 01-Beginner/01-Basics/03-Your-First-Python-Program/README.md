# Part 1 — What Is Visual Studio Code?

🌐 Language: **English** | [فارسی](fa/README.md)

In the previous lesson, you installed Python on your computer.

Now you need a place to write and manage your Python programs.

This is where **Visual Studio Code**, often called **VS Code**, comes in.

---

## What Is VS Code?

Visual Studio Code is a free source-code editor developed by Microsoft.

It helps you write, edit, organize, and run your code more efficiently.

Unlike the Python Interpreter, VS Code is not required to run Python.

Instead, it provides a comfortable environment for software development.

---

## Why Use VS Code?

VS Code is one of the most popular code editors in the world because it is:

- Free
- Lightweight
- Fast
- Cross-platform
- Easy to customize
- Supports hundreds of programming languages

It also has thousands of extensions that add new features.

---

## VS Code vs Python

Many beginners think VS Code is Python.

It isn't.

They have different roles.

| Python | Visual Studio Code |
|---------|--------------------|
| Programming language | Code editor |
| Executes programs | Helps write programs |
| Required | Optional |

Python is the engine.

VS Code is the workspace.

---

## Why Are We Using VS Code?

Throughout this book, all examples and exercises will be written in Visual Studio Code.

Using the same editor throughout the course keeps the learning experience simple and consistent.

---

## Part Summary

- VS Code is a free code editor.
- It is developed by Microsoft.
- It helps you write and manage code.
- VS Code is not Python.

# Part 2 — Downloading Visual Studio Code

Now that you know what Visual Studio Code is, it's time to download it.

VS Code is free and can be downloaded directly from the official Microsoft website.

---

## Download from the Official Website

Open your web browser and visit:

https://code.visualstudio.com

Always download Visual Studio Code from the official website.

This ensures that you receive:

- The latest stable version
- Official updates
- A secure installer
- The correct version for your operating system

---

The VS Code website automatically detects your operating system.

You will usually see a large download button for your device.

# Part 3 — Installing Visual Studio Code

After downloading Visual Studio Code, the next step is to install it.

The installation process is simple and usually takes only a few minutes.

---

## Run the Installer

Locate the installer you downloaded.

Its name will look similar to:

```text
VSCodeUserSetup-x64-1.xx.x.exe
```

Double-click the installer to launch the setup wizard.

---

## Accept the License Agreement

Read the license agreement.

Select:

```text
I accept the agreement
```

Then click **Next**.

> **See Figure 2.**

  <img src="images/License-Agreement.png" width="800" alt="License-Agreement">

<p align="center">

## Choose the Installation Location

The default installation location is recommended for most users.

Simply click **Next** to continue.

> 💡 **Tip**
>
> Unless you have a specific reason, keep the default installation folder.

---

## Select Additional Tasks

The installer allows you to enable several optional features.

We recommend enabling:

- ✔ Create a desktop icon
- ✔ Add "Open with Code" to the Windows Explorer context menu (files)
- ✔ Add "Open with Code" to the Windows Explorer context menu (directories)
- ✔ Register Code as an editor for supported file types
- ✔ Add to PATH
