# عنوان درس

از یک عنوان کوتاه، واضح و مناسب برای افراد مبتدی استفاده کنید.

نمونه‌ها:

- متغیرها
- شرط‌ها
- حلقه‌های While
- توابع

از عنوان‌های مبهم استفاده نکنید.

---

# ۱. معرفی (Overview)

## هدف

به‌صورت کوتاه موضوع درس را معرفی کنید.

بدون ورود به جزئیات فنی، به دانشجو بگویید قرار است چه چیزی یاد بگیرد.

## قوانین

- کوتاه بنویسید.
- از زبان ساده استفاده کنید.
- مخاطب را محور توضیح قرار دهید.
- از نوشتن کد در این بخش خودداری کنید.

---

# ۲. اهداف یادگیری (Learning Objectives)

## هدف

به‌صورت شفاف مشخص کنید که دانشجو پس از پایان این درس چه توانایی‌هایی خواهد داشت.

## قوانین

اهداف باید قابل اندازه‌گیری باشند.

هر هدف را با یک فعل مناسب شروع کنید.

نمونه‌ها:

- توضیح دهد...
- ایجاد کند...
- تشخیص دهد...
- استفاده کند...
- طراحی کند...

اهداف را کوتاه و واضح بنویسید.

---

# ۳. توضیح مفهوم (Concept Explanation)

## هدف

قبل از نمایش هر کدی، مفهوم اصلی را توضیح دهید.

به سؤالات زیر پاسخ دهید:

- این مفهوم چیست؟
- چرا به آن نیاز داریم؟
- چه زمانی از آن استفاده می‌کنیم؟

## قوانین

- از زبان ساده استفاده کنید.
- ابتدا درک مفهومی ایجاد کنید.
- از اصطلاحات غیرضروری خودداری کنید.
- مفاهیم پیچیده را به بخش‌های کوچک‌تر تقسیم کنید.

---

# ۴. مثال‌ها (Examples)

## هدف

با استفاده از مثال‌های کاربردی، نحوه استفاده از مفهوم را نشان دهید.

## قوانین

- هر مثال فقط یک مفهوم را آموزش دهد.
- مثال‌ها کوتاه باشند.
- از نام‌های معنی‌دار برای متغیرها استفاده شود.
- در صورت نیاز، خروجی مورد انتظار نمایش داده شود.
- تا جای ممکن از مثال‌های واقعی استفاده شود.

---

# ۵. نحوه عملکرد (How It Works)

## هدف

کد را مرحله‌به‌مرحله توضیح دهید.

هدف این بخش، درک منطق کد است.

## قوانین

- فقط خطوط مهم را توضیح دهید.
- توضیحات کوتاه باشند.
- روی درک مفهوم تمرکز کنید، نه حفظ کردن سینتکس.

---

# ۶. اشتباهات رایج (Common Mistakes)

## هدف

به دانشجو کمک کنید اشتباهات متداول را بشناسد و از آن‌ها جلوگیری کند.

## قوانین

برای هر اشتباه توضیح دهید:

- چرا رخ می‌دهد؟
- چگونه برطرف می‌شود؟
- چگونه می‌توان از آن جلوگیری کرد؟

---

# ۷. بهترین روش‌ها (Best Practices)

## هدف

از همان ابتدای مسیر، عادت‌های صحیح برنامه‌نویسی را آموزش دهید.

## قوانین

نمونه‌ها:

- استفاده از نام‌های مناسب
- خوانا نوشتن کد
- قالب‌بندی مناسب
- ترجیح سادگی بر پیچیدگی

---

# ۸. تمرین‌ها (Exercises)

## هدف

به دانشجو فرصت دهید تا مطالب درس را تمرین کند.

## قوانین

هر درس باید شامل سه سطح تمرین باشد:

🟢 ساده

تمرین یک مفهوم

🟡 متوسط

ترکیب چند مفهوم

🔴 چالشی

حل مسئله با استفاده از مفاهیم درس

---

# ۹. آزمون (Quiz)

## هدف

میزان درک دانشجو از مطالب درس را ارزیابی کنید.

## قوانین

سؤالات باید میزان فهم مطالب را بسنجند، نه حفظ کردن آن‌ها.

در صورت امکان از انواع مختلف سؤال استفاده کنید.

نمونه‌ها:

- چهارگزینه‌ای
- درست / نادرست
- پاسخ کوتاه
- تحلیل کد

---

# ۱۰. جمع‌بندی (Summary)

## هدف

مهم‌ترین نکات درس را مرور کنید.

## قوانین

- از Bullet Point استفاده کنید.
- مطلب جدیدی در این بخش آموزش داده نشود.

---

# ۱۱. درس بعدی (Next Lesson)

## هدف

موضوع درس بعد را به‌صورت کوتاه معرفی کنید.

در دانشجو انگیزه و کنجکاوی ایجاد کنید.

این بخش باید کوتاه باشد.

---

# قوانین نگارش درس

تمام درس‌ها باید:

- از Style Guide پروژه پیروی کنند.
- فقط یک موضوع اصلی را آموزش دهند.
- از ساده به پیچیده پیش بروند.
- با زبان مناسب افراد مبتدی نوشته شوند.
- شامل کدهای آزمایش‌شده باشند.
- مثال‌های کاربردی داشته باشند.
- تمرین داشته باشند.
- با جمع‌بندی به پایان برسند.
