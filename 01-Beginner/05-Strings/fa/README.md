# درس — رشته‌ها و Sequenceها

> 🌐 language: **فارسی** | [English](../README.md)

## بخش ۱ — رشته چیست؟ (`Strings`)

**رشته (`String`)** مجموعه‌ای مرتب از کاراکترهاست.

کاراکترها می‌توانند شامل موارد زیر باشند:

* حروف
* اعداد
* فاصله‌ها
* نمادها

در پایتون، رشته‌ها داخل علامت نقل قول نوشته می‌شوند.

برای مثال:

```python
name = "Python"
language = 'Python'
```

هر دو نمونه یک رشته ایجاد می‌کنند.

---

## ساخت یک رشته

می‌توانیم از علامت نقل قول تکی یا دوتایی استفاده کنیم:

```python
message = "Hello, Python!"
```

یا:

```python
message = 'Hello, Python!'
```

پایتون هر دو را به عنوان `String` در نظر می‌گیرد.

---

## رشته می‌تواند شامل کاراکترهای مختلف باشد

رشته فقط محدود به حروف نیست.

برای مثال:

```python
text = "Hello123"
```

این یک رشته شامل حروف و اعداد است.

می‌توانیم فاصله هم داشته باشیم:

```python
text = "Hello World"
```

و حتی نمادها:

```python
text = "Python @ 2026!"
```

تمام این موارد رشته هستند.

---

## رشته خالی

یک رشته می‌تواند هیچ کاراکتری نداشته باشد:

```python
empty = ""
```

به این مقدار **رشته خالی (`Empty String`)** گفته می‌شود.

طول آن صفر است.

---

## رشته‌ها Sequence هستند

رشته یک دنباله مرتب از کاراکترهاست.

برای مثال:

```python
word = "Python"
```

از نظر مفهومی:

```text
P  y  t  h  o  n
```

هر کاراکتر یک موقعیت مشخص دارد.

این موقعیت را **Index** می‌نامیم.

در بخش‌های بعدی یاد می‌گیریم چطور از Index استفاده کنیم.

---

## بررسی نوع داده

با استفاده از `type()` می‌توانیم نوع مقدار را بررسی کنیم:

```python
name = "Python"

print(type(name))
```

خروجی:

```text
<class 'str'>
```

`str` نوع داده داخلی پایتون برای رشته‌هاست.

---

## نکته مهم

رشته‌ها در پایتون **Immutable** هستند.

یعنی بعد از ساخته شدن یک رشته، نمی‌توانیم کاراکترهای آن را مستقیماً تغییر دهیم.

برای مثال، کد زیر مجاز نیست:

```python
word = "Python"

word[0] = "J"
```

پایتون در این حالت خطا ایجاد می‌کند.

در عوض باید یک رشته جدید بسازیم:

```python
word = "Python"

word = "J" + word[1:]

print(word)
```

خروجی:

```text
Jython
```

در بخش‌های مربوط به Index و Slicing بیشتر با این مفهوم کار خواهیم کرد.

---

## تفکر الگوریتمی

قبل از رفتن به بخش بعدی، به این مسئله فکر کنید:

فرض کنید نام کاربر را داریم:

```python
name = "Ahmad"
```

چطور می‌توانیم بفهمیم:

1. نام چند کاراکتر دارد؟
2. اولین کاراکتر چیست؟
3. آخرین کاراکتر چیست؟
4. آیا یک کاراکتر مشخص در نام وجود دارد یا نه؟

در ادامه درس، این سؤال‌ها را مرحله به مرحله پاسخ خواهیم داد.

---

## جمع‌بندی

یک String:

* یک دنباله از کاراکترهاست.
* داخل علامت نقل قول نوشته می‌شود.
* می‌تواند شامل حروف، اعداد، فاصله و نمادها باشد.
* می‌تواند خالی باشد.
* ترتیب دارد.
* Index دارد.
* از نوع `str` است.
* Immutable است.

در بخش بعدی یاد می‌گیریم چطور **به کاراکترهای یک رشته با استفاده از Index دسترسی پیدا کنیم**.
