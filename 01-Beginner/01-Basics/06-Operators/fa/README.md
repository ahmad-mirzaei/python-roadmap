# بخش ۱ — عملگر و عملوند چیست؟

🌐 Language: **فارسی** | [English](../README.md)

در برنامه نویسی معمولاً لازم است کارهایی مانند موارد زیر را انجام دهیم:

* جمع کردن عددها
* کم کردن مقدارها
* مقایسه دو اطلاعات
* ترکیب داده ها

برای انجام این کارها، پایتون از **عملگرها (Operators)** استفاده می کند.

---

## یک مثال روزمره

یک ماشین حساب را تصور کنید.

اگر بنویسید:

```text
5 + 3
```

ماشین حساب یک عملیات انجام می دهد.

* `5` یک مقدار است.
* `3` یک مقدار دیگر است.
* `+` به ماشین حساب می گوید این دو مقدار را با هم جمع کند.

در برنامه نویسی هم دقیقاً همین اتفاق می افتد.

---

## عملگر چیست؟

**عملگر (Operator)** نمادی است که به پایتون می گوید چه عملی انجام دهد.

نمونه ها:

```python
+
-
*
/
=
```

هر عملگر معنی مشخصی دارد.

---

## عملوند چیست؟

**عملوند (Operand)** مقداری است که عملگر روی آن کار می کند.

مثال:

```python
5 + 3
```

در این عبارت:

* `5` → عملوند
* `3` → عملوند
* `+` → عملگر

---

## مثال دیگر

```python
price = 100
discount = 20

final_price = price - discount
```

در عبارت:

```python
price - discount
```

* `price` یک عملوند است.
* `discount` یک عملوند است.
* `-` عملگر است.

پایتون عملوند دوم را از عملوند اول کم می کند.

---

## چرا عملگرها مهم هستند؟

بدون عملگرها، برنامه فقط می توانست اطلاعات را ذخیره کند و هیچ کاری روی آن ها انجام ندهد.

عملگرها به برنامه اجازه می دهند:

* مجموع را محاسبه کند.
* اختلاف را پیدا کند.
* مقدارها را مقایسه کند.
* تصمیم گیری کند.
* اطلاعات را به روز کند.

تقریباً تمام برنامه های پایتون از عملگرها استفاده می کنند.

---

## خلاصه این بخش

* **عملگر** نمادی است که یک عمل انجام می دهد.
* **عملوند** مقداری است که عملگر روی آن کار می کند.
* مثال:

```python
5 + 3
```

در این عبارت، `+` عملگر است و `5` و `3` عملوند هستند.

در بخش بعد با مهم ترین عملگرهای حسابی پایتون آشنا می شوید.

---

# بخش ۲ — عملگر های حسابی

در بخش قبل یاد گرفتید عملگر و عملوند چیست.

حالا نوبت آن است که با پرکاربرد ترین عملگر های پایتون آشنا شوید.

به این عملگر ها **عملگر های حسابی (Arithmetic Operators)** گفته می شود، زیرا برای انجام محاسبات ریاضی استفاده می شوند.

---

## یک مثال روزمره

یک ماشین حساب را تصور کنید.

وقتی وارد می کنید:

```
15 + 5
```

ماشین حساب عمل جمع را انجام می دهد.

اگر وارد کنید:

```
20 - 8
```

عمل تفریق انجام می شود.

پایتون نیز دقیقاً به همین شکل کار می کند.

برای انجام محاسبات ریاضی از عملگر های حسابی استفاده می کند.

---

## عملگر جمع (+)

عملگر جمع دو مقدار را با یکدیگر جمع می کند.

مثال:

```python
a = 10
b = 5

result = a + b

print(result)
```

خروجی:

```text
15
```

---

## عملگر تفریق (-)

عملگر تفریق یک مقدار را از مقدار دیگر کم می کند.

مثال:

```python
a = 20
b = 8

result = a - b

print(result)
```

خروجی:

```text
12
```

---

## عملگر ضرب (*)

عملگر ضرب دو مقدار را در یکدیگر ضرب می کند.

مثال:

```python
a = 6
b = 4

result = a * b

print(result)
```

خروجی:

```text
24
```

---

## عملگر تقسیم (/)

عملگر تقسیم یک مقدار را بر مقدار دیگر تقسیم می کند.

مثال:

```python
a = 20
b = 5

result = a / b

print(result)
```

خروجی:

```text
4.0
```

توجه کنید که نتیجه همیشه به صورت عدد اعشاری برگردانده می شود.

---

## عملگر تقسیم صحیح (//)

عملگر تقسیم صحیح دو عدد را بر هم تقسیم می کند و فقط بخش صحیح نتیجه را برمی گرداند.

مثال:

```python
a = 20
b = 6

result = a // b

print(result)
```

خروجی:

```text
3
```

قسمت اعشاری نتیجه حذف می شود.

---

## عملگر باقیمانده تقسیم (%)

عملگر `%` باقیمانده تقسیم دو عدد را برمی گرداند.

مثال:

```python
a = 20
b = 6

result = a % b

print(result)
```

خروجی:

```text
2
```

زیرا:

```
20 = (6 × 3) + 2
```

باقیمانده برابر با `2` است.

---

## عملگر توان (**)

عملگر `**` یک عدد را به توان عدد دیگر می رساند.

مثال:

```python
result = 2 ** 3

print(result)
```

خروجی:

```text
8
```

زیرا:

```
2 × 2 × 2 = 8
```

---

## خلاصه عملگر ها

| عملگر | کاربرد | مثال |
|-------|---------|------|
| `+` | جمع | `10 + 5` |
| `-` | تفریق | `20 - 8` |
| `*` | ضرب | `6 * 4` |
| `/` | تقسیم | `20 / 5` |
| `//` | تقسیم صحیح | `20 // 6` |
| `%` | باقیمانده تقسیم | `20 % 6` |
| `**` | توان | `2 ** 3` |

---

## اشتباه رایج مبتدیان

بسیاری از افراد مبتدی عملگر `/` و `//` را با هم اشتباه می گیرند.

مثال:

```python
20 / 6
```

خروجی:

```text
3.3333333333333335
```

اما:

```python
20 // 6
```

خروجی:

```text
3
```

عملگر `/` نتیجه واقعی تقسیم را برمی گرداند.

عملگر `//` فقط بخش صحیح نتیجه را برمی گرداند.

---

## خلاصه این بخش

- عملگر های حسابی برای انجام محاسبات ریاضی استفاده می شوند.
- پایتون هفت عملگر حسابی اصلی دارد.
- `/` و `//` دو عملگر متفاوت هستند.
- `%` باقیمانده تقسیم را برمی گرداند.
- `**` برای محاسبه توان استفاده می شود.

---

# بخش ۳ — عملگر های انتساب

در درس های قبلی بارها از عملگر انتساب استفاده کرده اید.

برای مثال:

```python
age = 36
```

اما واقعاً این خط چه کاری انجام می دهد؟

عملگر انتساب یک مقدار را داخل یک متغیر قرار می دهد.

پایتون علاوه بر عملگر `=` چند عملگر میانبر هم دارد که باعث می شوند کد کوتاه تر و خواناتر شود.

---

## عملگر انتساب (=)

عملگر `=` یک مقدار را به یک متغیر اختصاص می دهد.

مثال:

```python
score = 100
```

حالا متغیر `score` مقدار `100` را نگهداری می کند.

---

## جمع و انتساب (+=)

به جای نوشتن:

```python
score = score + 10
```

می توانید بنویسید:

```python
score += 10
```

هر دو دقیقاً یک نتیجه دارند.

---

## تفریق و انتساب (-=)

مثال:

```python
score -= 5
```

یعنی:

```python
score = score - 5
```

---

## ضرب و انتساب (*=)

مثال:

```python
score *= 2
```

یعنی:

```python
score = score * 2
```

---

## تقسیم و انتساب (/=)

مثال:

```python
score /= 4
```

یعنی:

```python
score = score / 4
```

---

## جدول خلاصه

| عملگر | معادل |
|-------|--------|
| `=` | اختصاص مقدار |
| `+=` | `x = x + value` |
| `-=` | `x = x - value` |
| `*=` | `x = x * value` |
| `/=` | `x = x / value` |

---

- نتیجه را بر 2 تقسیم کنید.

در پایان مقدار نهایی را چاپ کنید.

# بخش ۴ — عملگر های مقایسه ای

برنامه ها قبل از تصمیم گیری باید مقدار ها را با هم مقایسه کنند.

برای مثال:

- آیا سن کاربر برای ثبت نام کافی است؟
- آیا رمز عبور درست وارد شده است؟
- آیا نمره بیشتر از 90 است؟

پایتون برای انجام این مقایسه ها از **عملگر های مقایسه ای** استفاده می کند.

نتیجه هر مقایسه فقط یکی از دو مقدار زیر است:

- `True`
- `False`

---

## مساوی (==)

عملگر `==` بررسی می کند که آیا دو مقدار با هم برابر هستند یا نه.

مثال:

```python
print(10 == 10)
```

خروجی:

```text
True
```

مثال:

```python
print(10 == 5)
```

خروجی:

```text
False
```

---

## نامساوی (!=)

عملگر `!=` بررسی می کند که آیا دو مقدار با هم متفاوت هستند یا نه.

مثال:

```python
print(10 != 5)
```

خروجی:

```text
True
```

---

## بزرگ تر (>)

بررسی می کند آیا مقدار سمت چپ بزرگ تر از مقدار سمت راست است.

مثال:

```python
print(20 > 15)
```

خروجی:

```text
True
```

---

## کوچک تر (<)

بررسی می کند آیا مقدار سمت چپ کوچک تر از مقدار سمت راست است.

مثال:

```python
print(7 < 3)
```

خروجی:

```text
False
```

---

## بزرگ تر یا مساوی (>=)

مثال:

```python
print(18 >= 18)
```

خروجی:

```text
True
```

---

## کوچک تر یا مساوی (<=)

مثال:

```python
print(12 <= 20)
```

خروجی:

```text
True
```

---

## جدول عملگر های مقایسه ای

| عملگر | کاربرد |
|-------|--------|
| `==` | مساوی |
| `!=` | نامساوی |
| `>` | بزرگ تر |
| `<` | کوچک تر |
| `>=` | بزرگ تر یا مساوی |
| `<=` | کوچک تر یا مساوی |

---

# بخش ۵ — عملگر های منطقی

گاهی اوقات مقایسه فقط یک شرط کافی نیست.

برای مثال:

- آیا سن کاربر بیشتر از 18 سال است **و** کارت شناسایی دارد؟
- آیا امروز شنبه **یا** یکشنبه است؟
- آیا رمز عبور **خالی نیست**؟

پایتون برای ترکیب یا تغییر شرط ها از **عملگر های منطقی** استفاده می کند.

سه عملگر منطقی اصلی عبارت اند از:

- `and`
- `or`
- `not`

---

## عملگر `and`

عملگر `and` فقط زمانی مقدار `True` برمی گرداند که **هر دو شرط** درست باشند.

مثال:

```python
age = 36
has_id = True

print(age >= 18 and has_id)
```

خروجی:

```text
True
```

اگر حتی یکی از شرط ها نادرست باشد، نتیجه کل عبارت `False` خواهد بود.

---

## عملگر `or`

عملگر `or` زمانی مقدار `True` برمی گرداند که **حداقل یکی از شرط ها** درست باشد.

مثال:

```python
is_saturday = False
is_sunday = True

print(is_saturday or is_sunday)
```

خروجی:

```text
True
```

فقط زمانی نتیجه `False` می شود که هر دو شرط نادرست باشند.

---

## عملگر `not`

عملگر `not` نتیجه یک شرط را برعکس می کند.

مثال:

```python
is_logged_in = False

print(not is_logged_in)
```

خروجی:

```text
True
```

---

## جدول عملگر های منطقی

| عملگر | کاربرد |
|-------|--------|
| `and` | هر دو شرط باید درست باشند |
| `or` | حداقل یکی از شرط ها باید درست باشد |
| `not` | نتیجه را برعکس می کند |

---

## یک مثال روزمره

فرض کنید وارد یک وب سایت می شوید.

برای ورود باید:

- نام کاربری درست باشد.
- رمز عبور درست باشد.

هر دو شرط باید برقرار باشند.

این دقیقاً کاربرد عملگر `and` است.

مثال دیگر:

یک سینما در **شنبه یا یکشنبه** تخفیف دارد.

وجود یکی از این دو روز کافی است.

این مثال کاربرد عملگر `or` را نشان می دهد.

# عملگرها — تقدم عملگرها

در این بخش با مفهوم **Operator Precedence یا تقدم عملگرها** در Python آشنا می شویم.

تقدم عملگرها مشخص می کند وقتی چند عملگر در یک عبارت وجود دارند، **Python کدام عملیات را زودتر انجام می دهد**.

شناخت تقدم عملگرها مهم است، چون ترتیب اجرای عملیات می تواند نتیجه نهایی یک عبارت را کاملا تغییر دهد.

---

## ۱. تقدم عملگر چیست؟

به این عبارت توجه کن:

```python
result = 2 + 3 * 4

print(result)
```

نتیجه:

```text
14
```

چرا نتیجه `20` نیست؟

چون Python ابتدا ضرب را انجام می دهد و سپس جمع:

```text
3 * 4 = 12
2 + 12 = 14
```

پس Python این عبارت را عملا به شکل زیر ارزیابی می کند:

```python
2 + (3 * 4)
```

نه:

```python
(2 + 3) * 4
```

---

## ۲. پرانتز بالاترین اولویت را دارد

پرانتز می تواند ترتیب معمول اجرای عملیات را تغییر دهد.

```python
result = (2 + 3) * 4

print(result)
```

خروجی:

```text
20
```

بدون پرانتز:

```python
result = 2 + 3 * 4

print(result)
```

خروجی:

```text
14
```

بنابراین پرانتز ساده ترین راه برای مشخص کردن ترتیب اجرای عملیات است.

---

## ۳. ترتیب کلی تقدم عملگرها

یک ترتیب ساده شده از تقدم عملگرها در Python به شکل زیر است:

| اولویت | عملگرها                               | توضیح                             |
| ------ | ------------------------------------- | --------------------------------- |
| ۱      | `()`                                  | پرانتز                            |
| ۲      | `**`                                  | توان                              |
| ۳      | `+x` ، `-x`                           | مثبت و منفی یکانی                 |
| ۴      | `*` ، `/` ، `//` ، `%`                | ضرب، تقسیم، تقسیم صحیح، باقیمانده |
| ۵      | `+` ، `-`                             | جمع و تفریق                       |
| ۶      | `==` ، `!=` ، `<` ، `<=` ، `>` ، `>=` | مقایسه                            |
| ۷      | `not`                                 | NOT منطقی                         |
| ۸      | `and`                                 | AND منطقی                         |
| ۹      | `or`                                  | OR منطقی                          |

هرچه یک عملگر بالاتر قرار داشته باشد، معمولا زودتر اجرا می شود.

---

## ۴. ضرب قبل از جمع

به این مثال توجه کن:

```python
result = 10 + 5 * 2

print(result)
```

Python ابتدا:

```text
5 * 2 = 10
```

و سپس:

```text
10 + 10 = 20
```

بنابراین:

```text
20
```

اگر بخواهیم ابتدا جمع انجام شود:

```python
result = (10 + 5) * 2

print(result)
```

حالا:

```text
15 * 2 = 30
```

خروجی:

```text
30
```

---

## ۵. تقسیم و ضرب

عملگرهای زیر در یک سطح از تقدم قرار دارند:

```text
*
/
//
%
```

برای مثال:

```python
result = 20 / 5 * 2

print(result)
```

این عملیات از **چپ به راست** انجام می شود:

```text
20 / 5 = 4
4 * 2 = 8
```

خروجی:

```text
8.0
```

مثال دیگر:

```python
result = 20 * 5 / 2

print(result)
```

ابتدا:

```text
20 * 5 = 100
```

سپس:

```text
100 / 2 = 50
```

---

## ۶. جمع و تفریق

جمع و تفریق نیز در یک سطح از تقدم قرار دارند.

Python آنها را از چپ به راست ارزیابی می کند.

```python
result = 20 - 5 + 2

print(result)
```

مراحل:

```text
20 - 5 = 15
15 + 2 = 17
```

پس نتیجه:

```text
17
```

این عبارت معادل است با:

```python
result = (20 - 5) + 2
```

---

## ۷. عملگر توان

عملگر `**` تقدم بیشتری نسبت به ضرب، تقسیم، جمع و تفریق دارد.

```python
result = 2 + 3 ** 2

print(result)
```

Python ابتدا:

```text
3 ** 2 = 9
```

و سپس:

```text
2 + 9 = 11
```

پس خروجی:

```text
11
```

این عبارت معادل است با:

```python
result = 2 + (3 ** 2)
```

---

## ۸. توان و پرانتز

به این مثال توجه کن:

```python
result = (2 + 3) ** 2

print(result)
```

ابتدا:

```text
2 + 3 = 5
```

سپس:

```text
5 ** 2 = 25
```

خروجی:

```text
25
```

حالا آن را با این عبارت مقایسه کن:

```python
result = 2 + 3 ** 2

print(result)
```

خروجی:

```text
11
```

پرانتز ترتیب عملیات را کاملا تغییر داده است.

---

## ۹. مثبت و منفی یکانی

عملگرهای یکانی روی یک مقدار کار می کنند.

برای مثال:

```python
x = -5
y = +5

print(x)
print(y)
```

در اینجا:

```python
-5
+5
```

عملیات یکانی هستند.

این موضوع با جمع و تفریق معمولی فرق دارد:

```python
5 - 3
```

و:

```python
5 + 3
```

---

## ۱۰. مثال مهم `**` و منفی

به این عبارت توجه کن:

```python
result = -2 ** 2

print(result)
```

نتیجه:

```text
-4
```

چرا؟

چون توان تقدم بیشتری نسبت به منفی یکانی دارد:

```text
2 ** 2 = 4
-4
```

اگر بخواهیم خود عدد منفی را به توان برسانیم:

```python
result = (-2) ** 2

print(result)
```

خروجی:

```text
4
```

این یکی از مثال های مهمی است که نشان می دهد چرا استفاده درست از پرانتز اهمیت دارد.

---

## ۱۱. Modulo و Floor Division

عملگرهای زیر در یک سطح از تقدم قرار دارند:

```text
*
/
//
%
```

برای مثال:

```python
result = 17 % 5 + 2

print(result)
```

ابتدا:

```text
17 % 5 = 2
```

سپس:

```text
2 + 2 = 4
```

پس خروجی:

```text
4
```

مثال دیگر:

```python
result = 17 // 5 * 2

print(result)
```

ابتدا:

```text
17 // 5 = 3
```

سپس:

```text
3 * 2 = 6
```

---

## ۱۲. عملگرهای مقایسه ای

عملگرهای مقایسه ای تقدم پایین تری نسبت به عملگرهای حسابی دارند.

مثال:

```python
result = 10 + 5 > 12

print(result)
```

Python ابتدا:

```text
10 + 5 = 15
```

سپس:

```text
15 > 12
```

در نتیجه:

```text
True
```

این عبارت معادل است با:

```python
result = (10 + 5) > 12
```

---

## ۱۳. چند مقایسه پشت سر هم

Python از مقایسه های زنجیره ای نیز پشتیبانی می کند.

مثال:

```python
age = 20

result = 18 <= age < 30

print(result)
```

خروجی:

```text
True
```

این عبارت عملا بررسی می کند که:

```python
18 <= age and age < 30
```

مقایسه های زنجیره ای یکی از قابلیت های کاربردی Python هستند.

---

## ۱۴. تقدم `not`، `and` و `or`

ترتیب تقدم عملگرهای منطقی به صورت زیر است:

```text
not
and
or
```

بنابراین:

```python
result = True or False and False

print(result)
```

ابتدا `and` اجرا می شود:

```text
False and False = False
```

سپس:

```text
True or False = True
```

نتیجه:

```text
True
```

این عبارت معادل است با:

```python
result = True or (False and False)
```

---

## ۱۵. استفاده از پرانتز با عملگرهای منطقی

به این عبارت توجه کن:

```python
result = (True or False) and False

print(result)
```

ابتدا:

```text
True or False = True
```

سپس:

```text
True and False = False
```

خروجی:

```text
False
```

مقایسه کن:

```python
True or False and False
```

با:

```python
(True or False) and False
```

نتیجه آنها متفاوت است، چون پرانتز ترتیب اجرای عملیات را تغییر داده است.

```text
28
```

ابتدا:

سپس:

Python ابتدا مقایسه را انجام می دهد:

```text
age >= 18
```

```text
True
```

است.

سپس:

```text

```

بنابراین:

```text
True
```

## ۱۹. مثال ترکیبی حسابی و Boolean

```python
x = 10

result = x + 5 > 12 and x * 2 == 20

print(result)
```

Python ابتدا عملیات حسابی را انجام می دهد:

```text
x + 5 = 15
x * 2 = 20
```

سپس مقایسه ها انجام می شوند:

```text
15 > 12
20 == 20
```

هر دو نتیجه `True` هستند.

در نهایت:

```text
True and True
```

پس نتیجه:

```text
True
```

## ۲۰. پرانتز به عنوان یک روش خوب

حتی اگر تقدم عملگرها را به خوبی بلد باشیم، استفاده از پرانتز می تواند کد را خواناتر کند.

به جای:

```python
result = age >= 18 and score >= 60 or has_permission
```

می توانیم بنویسیم:

```python
result = (age >= 18 and score >= 60) or has_permission
```

نسخه دوم واضح تر است و خواننده سریع تر متوجه منطق عبارت می شود.

در عبارت های پیچیده، استفاده از پرانتز معمولا انتخاب بهتری است.

# خلاصه نهایی

مهم ترین ترتیب تقدم عملگرها که باید به خاطر بسپاریم:

```text
()
**
+x, -x
*, /, //, %
+, -
comparisons
not
and
or
```

یک مدل ذهنی ساده:

```text
پرانتز
   ↓
توان
   ↓
ضرب / تقسیم
   ↓
جمع / تفریق
   ↓
مقایسه
   ↓
not
   ↓
and
   ↓
or
```

اگر درباره ترتیب اجرای یک عبارت مطمئن نیستی، از پرانتز استفاده کن.

کدی که واضح باشد معمولا بهتر از کدی است که فقط به حفظ کردن تمام قوانین تقدم وابسته باشد.

# تمرین های پایان بخش

```python
result = 2 + 3 * 4
```

### سوال ۲

```python
result = (2 + 3) * 4
```

```python
result = 2 + 3 ** 2 * 2
```

```python
-2 ** 2
```

و:

```python
(-2) ** 2
```

```python
result = True or False and False
```

```python
result = 10 + 5 * 2 > 15 and 20 % 3 == 2
```

# سوال جامع

بدون اجرای کد، مقدار نهایی هر عبارت را مشخص کن و ترتیب اجرای عملگرها را توضیح بده:

```python
a = 2 + 3 * 4
b = (2 + 3) * 4
c = 2 ** 3 * 2 + 1
d = -2 ** 2
e = (-2) ** 2
f = 20 / 5 * 2
g = 20 - 5 + 2
h = True or False and False
i = (True or False) and False
j = 10 + 2 * 3 ** 2 > 25 and 20 % 3 == 2
```

برای هر عبارت:

1. بالاترین عملگر دارای تقدم را مشخص کن.
2. عبارت را مرحله به مرحله محاسبه کن.
3. نتیجه نهایی را بنویس.
4. توضیح بده آیا استفاده از پرانتز می تواند عبارت را خواناتر کند یا نه.
