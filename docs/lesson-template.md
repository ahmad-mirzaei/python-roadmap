# 📚 Lesson Template

> 🌐 Language: **English** | [فارسی](fa/lesson-template.md)

> This document defines the standard structure for every lesson in the Python Roadmap project.
>
> Every lesson should follow this template to ensure consistency, readability, and high educational quality across the entire roadmap.

---

# Lesson Title

Use a short, descriptive, and beginner-friendly title.

Examples:

- Variables
- If Statements
- While Loops
- Functions

Avoid vague titles.

---

# 1. Overview

## Purpose

Briefly introduce the lesson.

Explain what learners are about to learn without going into technical details.

## Guidelines

- Keep it short.
- Write in plain English.
- Focus on the learner.
- Avoid code.

---

# 2. Learning Objectives

## Purpose

Clearly describe what learners will be able to do after completing this lesson.

## Guidelines

Objectives should be measurable.

Start each objective with an action verb.

Examples:

- Explain ...
- Create ...
- Identify ...
- Use ...
- Build ...

Keep objectives concise.

---

# 3. Concept Explanation

## Purpose

Explain the concept before introducing code.

Answer questions such as:

- What is it?
- Why does it exist?
- When should it be used?

## Guidelines

- Use simple language.
- Build intuition first.
- Avoid unnecessary terminology.
- Break complex ideas into smaller parts.

---

# 4. Examples

## Purpose

Demonstrate how the concept works using practical examples.

## Guidelines

- One concept per example.
- Keep examples small.
- Use meaningful variable names.
- Include the expected output whenever appropriate.
- Prefer real-world scenarios.

---

# 5. How It Works

## Purpose

Explain the example step by step.

Help learners understand the reasoning behind the code.

## Guidelines

- Explain only important lines.
- Keep explanations concise.
- Focus on understanding instead of syntax memorization.

---

# 6. Common Mistakes

## Purpose

Help learners recognize and avoid common beginner mistakes.

## Guidelines

For each mistake explain:

- Why it happens.
- How to fix it.
- How to avoid it.

---

# 7. Best Practices

## Purpose

Introduce professional programming habits from the beginning.

## Guidelines

Examples may include:

- Meaningful variable names
- Readable code
- Consistent formatting
- Simplicity over cleverness

---

# 8. Exercises

## Purpose

Allow learners to practice what they have learned.

## Guidelines

Every lesson should include:

🟢 Basic

Simple practice of one concept.

🟡 Intermediate

Practice combining multiple concepts.

🔴 Challenge

Problem-solving exercise requiring independent thinking.

---

# 9. Quiz

## Purpose

Check understanding of the lesson.

## Guidelines

Questions should test understanding rather than memorization.

Include different question types whenever appropriate.

Examples:

- Multiple Choice
- True / False
- Short Answer
- Code Reading

---

# 10. Summary

## Purpose

Review the most important ideas from the lesson.

## Guidelines

Use short bullet points.

Do not introduce new concepts.

---

# 11. Next Lesson

## Purpose

Briefly introduce the next lesson.

Create curiosity about what comes next.

Keep this section short.

---

# Writing Rules

Every lesson should:

- Follow the project Style Guide.
- Teach one main topic.
- Progress from simple to advanced.
- Use beginner-friendly language.
- Include tested code.
- Include practical examples.
- Include exercises.
- End with a summary.

---

# Final Checklist

Before publishing a lesson, verify that:

- [ ] The lesson follows the standard structure.
- [ ] All code examples have been tested.
- [ ] Variable names are meaningful.
- [ ] Examples are practical.
- [ ] Common mistakes are included.
- [ ] Best practices are included.
- [ ] Exercises cover multiple difficulty levels.
- [ ] The quiz checks understanding.
- [ ] The summary reviews the lesson.
- [ ] The next lesson is introduced.
